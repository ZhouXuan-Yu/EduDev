# 文档索引

本目录用于沉淀 Omni-Edu Agent 第一阶段开发所需的产品、数据、架构和任务文档。

当前版本定位：

> 面向单个老师个人使用的本地学生档案与个性化复盘助手。

第一阶段不做团队协作、不做云同步、不做机构管理系统。优先验证一个老师是否愿意把学生资料长期放进本地系统，并用它生成阶段复盘。

## 第一阶段最小闭环

```text
创建学生 -> 添加学习记录 -> 上传附件 -> 本地保存 -> 时间线查看 -> 生成阶段复盘
```

这个闭环跑通以后，再接入 OCR、错题识别、本地向量检索和自动组卷。
