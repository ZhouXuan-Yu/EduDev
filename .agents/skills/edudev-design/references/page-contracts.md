# 页面契约与功能保留

统一的是层级、操作语义、组件与状态，不是让全部页面使用同一三栏模板。

| 页面类型 | 首屏与主要行动 | 渐进内容 / 迁移去向 |
| --- | --- | --- |
| 空白对话 | 短欢迎、居中输入、轻量任务入口、最多少量示例 | 右栏关闭；高级选项进入菜单，保留当前值可见与可访问 |
| 进行中对话 | 阅读区为主、输入固定在中间区域底部；停止明确可达 | 公开过程在正文交接时收起；工具详情按需；文件/审批有提示，不强开右栏 |
| 资料库 | 搜索、导入、实际列表；选中资料后显示概要与预览 | 原文/两遍解析/识别对照与诊断各自可展开，避免全部长记录同屏；保留证据与教师校正 |
| 教学工作台 | 以真实教学文件/备课任务为主体，主要行动贴近内容 | 备课本/讲义/题本/组卷在页内导航，不重复左栏菜单与大入口网格 |
| 学生工作台 | 搜索、学生列表；未选中为有行动的空态 | 选中后记录/错题/计划/复盘/概览同一上下文；查找与录入在相关视图，保留档案CRUD |
| 设置（提案） | 清晰分类、标签/控件对齐、按配置组保存反馈 | 常用与高级分层待确认；权限风险在实际操作处显示，不藏入诊断 |
| 创建/编辑 | 单一任务、明确返回、就近保存与状态 | 长任务主区，短局部编辑用弹窗；未保存离开需保护，不能滥用侧栏承载复杂表单 |

## 迁移清单（正式实施时逐项核验）

- 左栏仍可新建/搜索/查看历史与教学空间；四主入口＋底部设置。长历史不能让主目的页永久不可见，可收起分组或限制历史区滚动，但不新增多重纵向滚动陷阱。
- 原15目的页不删除：问小智、资料库、教学文件、备课本、讲义、题本、组卷；学生档案、查找、录入、错题、计划、复盘、概览；设置。旧直达入口在替代路径运行验收前保持兼容。
- 教学空间仍是会话文件夹，不默认为授权目录。列表/文件/学生必须来自原真源。
- 迁移只移可见入口：原 route ID、查询参数、权限/disabled守卫、文件绑定、冷启恢复不变；需变更时单列契约。

## 滚动与窄窗

Header/Footer不滚动，中间内容承担明确滚动。对话只有消息区纵向滚动，composer不被正文推走；空首页在目标窗口需无需滚动即可开始输入。列表和详情可分别滚动，但不得同一文本被两个容器竞争；弹层受 viewport约束。窄窗先收起右栏，再将左栏改为显式可打开的导航，不能把正文挤成窄缝或把输入覆盖。
