# 观察记录

本轮截图来自 JPEG 压缩的桌面工具输出；小字模糊、笔画缺失可能与采集链路有关，需在应用窗口或无损截图中复核，不能直接归因产品。以下仅记录画面可见现象。

## I01 资料详情侧栏信息拥挤（P2）

- 证据：[资料详情](images/P03-library-detail.png)。窄侧栏中长标题换行，六个分区标签分成两行，正文统计落在首屏底部之外。教师需滚动并在相邻标签中查找内容。
- 复现：资料库选择第一份资料，查看概要侧栏。需在目标窗口尺寸和实际交互下进一步核实。

## I02 学生目录搜索提示被截断（P2）

- 证据：[学生工作台](images/P10-students.png)。搜索框提示语末尾被裁切；教师无法从提示语完整了解可搜索字段。
- 复现：进入学生工作台，观察左侧搜索框。需确认聚焦或悬停是否提供完整提示。

## I03 学生档案表单首屏无法看到保存操作（P2）

- 证据：[学生档案](images/P11-student-form.png)。新建表单首屏仅显示部分字段，创建按钮在可见区域外；教师需要继续滚动才能完成操作。
- 复现：学生工作台 → 添加学生。需要进一步检查滚动后按钮与返回路径。

## I04 任务标题截断可能丢失约束（P2）

- 证据：[我的任务](images/P02-tasks-current.png)。任务标题以截断文本显示，完整说明另在卡片正文；标题和正文涉及现有会话内容，公开图已遮盖。截断可能使教师单看标题时漏掉末尾约束。
- 复现：我的任务 → 任务总览，观察长标题。需进一步核实悬停和键盘访问。
