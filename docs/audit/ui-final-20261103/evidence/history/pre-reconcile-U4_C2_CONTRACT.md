# U4-C2 · 真实参考卷、独立模板与实际版式交付合同

2026-11-02。基线fdaa460，任务分支codex/ui-goal-implementation-20261101；D日常及三个已启动验收窗口保留。本合同从属于UI_DESIGN_IMPLEMENTATION_V2、QUESTION_STUDIO及Master，不缩减完整Goal。Sol实施、Astra规划/独立审查，父负责实际Electron/文件核验与正常Git整合。当前尚未实现或验收C2。

## 教师结果与真实缺口

教师从当前非空题篮选择真实参考资料，检查原文依据并修订提取候选，将命题结构和卷面规则分别存为不可变模板版本；明确选择应用结构、版式或两者，手选题和本卷实例不被覆盖。确认后的实际Word/PDF使用同一冻结版式与当前卷身份。模板库新版本不能倒灌旧篮、旧确认卷或历史文件。

目前正式生产只有资料导入/本地解析、蓝图、持久题篮/CAS/实例审核、D1精确卷与原Office审批/安装来源守卫。HTML参考卷为固定示例；paper-basket-reference只是导航；paper/answer_sheet是输出种类，不是卷面模板。现有WordDocument没有纸张/边距/分栏，OfficeDraft及Word/PDF为固定页面；这些缺口须实际补齐，不能仅保存名称或添加预览CSS。

## 全链路与连续实施顺序

1. **C2a真实候选**：沿现有资料导入和已导入资料选择，主进程从确切resourceId/version的实际内容确定性提取有来源的候选；typed IPC/preload贯通正式组卷页；教师可编辑、取消、查看原文依据和未知/歧义。不得返回固定示例、从文件名猜字段、把首段当全文或把默认A4当识别结果。
2. **C2b模板版本/应用**：同SQLite最小不可变版本与幂等记录；明确保存新版本不改当前篮。应用结构/版式/两者具备来源复核、owner/学生边界、active、CAS、请求幂等和事务一致性。独立应用互不改写，全部现有entryId、questionId/source、实例内容/审核事件保留；不适配条目留在篮中并提示，分节映射需教师明确确认。
3. **C2c冻结快照/Office**：受限布局及确切模板版本进入篮与确认快照/digest/current性，D1沿paperId/digest捕获实际布局；原Office审批与安装前源锁继续。正式预览、实际DOCX/XML与PDF版式读回一致，不能以保存设置值代替实际输出。

这些是连续实施片，不是三个可替代目标。a或b完成不能关闭C2或将未实现的保存/应用/输出按钮伪装可用。先按当前合同实施a，审查共享接口/来源约束后追加b/c精确写集，整体目标保持。

## 数据、来源与候选约束

- 候选与严格可组卷蓝图分开；候选允许unknown/ambiguous/unsupported。字段保存实际提取值、定位证据、教师修订值及确认状态；缺失难度/知识点不补假值。
- 至少绑定resourceId/contentHash及实际正文/Word结构digest、读取范围、完整性和解析器版本。主进程复核原件及读取后版本；部分收录、读取上限、混合节页面规则必须显式显示。取消/来源失效/迟到结果不能覆盖当前教师输入。
- 资料原件、正文、题库继续原权威，不复制全文/图片成为另一题库。新结构数据在同SQLite增量幂等迁移，无修改既有表含义或删除原件。
- 原整数同节等分蓝图约束保留；小数、不等分、选做题、跨页小题等不可静默取整/拆大题。无法可靠转换时保留依据并要求明确修订；只有通过原validPaperBlueprint才能应用。
- 结构保存不改变来源策略/配额；应用保留当前source_only/hybrid/ai_original策略及教师确认来源边界。不能通过模板把未确认AI题塞入题篮。
- 引用原卷的候选与模板在保存/应用/确认和导出前按确切版本复核来源。原卷变化明确拒绝，不隐式脱离来源或回退latest。若以后允许脱离来源，须另立显式教师确认合同。
- 模板内容与版本不可变；另存v2不修改v1。跨会话复用须遵循实际教师/学生来源权限，不复制学生上下文；精确可复用范围在b的接口冻结中说明，不能绕过owner校验。

## 受限版式与真实输出约束

- 布局只接受版本化白名单数值规则：A4、竖/横向、单/双栏、边距、栏间距；只启用Word和PDF均实际支持的组合。无任意CSS/HTML/URL/路径或字体下载。
- DOCX可经现有MaterialRepository.original/version和有界readWordPackage读取OOXML页面属性；页设置无法可靠识别、PDF/扫描无法还原的属性必须待教师填写。解析外部关系/宏不执行，压缩包及XML上限和取消有效。
- 标题/考生信息跨栏、正文分栏、长题/图片/表格/公式宽度及分页按明确规则处理；不能仅外层columns=2而内部仍按整页宽绘制。不得裁切、隐藏或漏掉题目。
- 学生卷、教师卷、答题卡对布局的适用范围明确；不允许某一输出静默忽略所选版式。学生答案、解析及其图片在构造数据时隔离，不能只靠CSS隐藏。
- 新schema严格区分扩展，旧schema/hash/默认文件输出及旧持久数据可继续读取；不能让旧客户端静默丢失新布局后导出。题篮变动、布局移除/应用使旧确认失效，历史快照完整保留。

renderer在现有paper-ui下新增来源选择/候选核对/字段编辑及窄hook，PaperBasketWorkspace接入现有组卷页；复用HeroUI控件和DisclosureCard，不复制原型假数据，不修改输入组件、vendor源码/配置、全局CSS或增加依赖。来源选择先读已导入资料，需新导入时走现有资料库，不另造文件权限入口。

新增本片source/contract/IPC/mounted renderer测试；独立QA脚本由Goodall负责，不与Sol生产写集交叉。每段完成冻结逐文件SHA与适用命令，审查通过后继续下一段，不自动调用模型或反复构建。

布局采用现有浅色基线、紧凑对齐的来源/提案/确认操作，未知与证据渐进展示；禁止原生details/summary黑三角。新增核对面板按[HeroUI Modal](https://heroui.com/en/docs/react/components/modal)及[Accordion](https://heroui.com/en/docs/react/components/accordion)公开结构和项目组件边界复用；不能为验收随意覆盖官方状态样式。

## C2b/c追加接口边界（Astra审查，2026-11-02）

- 模板scope由宿主从实际来源推导，不接受renderer将学生来源声明为teacher。教师模板仅在同一dataRoot的有效会话中复用；学生模板仅允许同一有效学生。list/read/save/apply均检查资格，不复制原会话授权、审核记录或题目。C2a保守拒绝学生私有资料，不能据此声称学生模板复用已完成。
- 模板保存采用expectedHeadVersion/requestId；旧版本内容不可变。应用结构必须显式将每个模板分节映射到一个现有sectionId或新分节，禁止猜测同名、重复映射、自动一对多/多对一。应用本身保留所有entry.sectionId/entryId/题目及实例事实；未纳入新结构的旧分节和不适配条目原样保留，阻止确认并提示后续明确移题。结构和布局同时应用在一次事务、一个篮修订中完成。
- 受限布局统一为`xiaozhi.paper-layout.v1`，纸张A4，orientation=portrait/landscape，columns=1/2，margins及columnGap为整数0.1mm。固定原字体字号；不开放CSS、URL、任意字体或混合方向。除单项范围外校验实际栏宽及正文高度。四种方向/栏数组合必须逐一经过真实Word/PDF验证后才称支持。
- Word卷头单栏，正文通过连续分节进入所选栏数；PDF卷头置于分栏容器外，左栏后右栏。统一几何函数计算页面、栏宽和可用高度，图片、公式和表格按实际栏宽排版，不复用整页固定宽度。不可安全排入的不可拆图表明确拒绝，长题按段落续排而非整个题块强制不换页。
- 旧篮/快照缺少layout时保持旧默认输出和原digest分支，不读取即回写。首次应用版式进入明确的新快照schema，固定布局值、模板确切版本和来源证据进入digest。新版Office能力判定覆盖数学/表格/授权图片、图片审核、学生内容隔离和answer_sheet，安装前确定性比较同时覆盖布局。D1继续精确paperId/digest，不回退latest或模型版式。
- 并行基础写集仅为新增shared/paper-layout.ts及窄布局几何/DOCX/PDF辅助文件和对应测试，不接线Office旧入口、不改原输出；由同一C2c集成负责人在b快照schema冻结后贯通。基础测试不是实际Pi导出或完整C2c验收。

## 取消、失败与恢复

取消核对不新增模板版本、不改题篮/题库/确认/授权/输出文件；已显式完成的资料导入及可重建解析缓存单独记账，不宣称绝对磁盘零写入。预提交取消回滚，已提交后不得报“取消未保存”。读回失败用原幂等请求核实，不重复建版本；导航/切换source/basket/session的epoch及脏稿保护贯通，迟到结果不可自动应用。

回退先关闭新准备入口，保留新schema读器/历史快照/来源与布局拒绝，避免降成无布局或无来源导出。新增表不删除，旧资料/篮/确认/产物不回滚销毁。完整回退演练另记，不能用兼容测试冒称已演练。

## 验收标准与证据

1. 当前生产UI的非空手选篮，实际导入并选择两份内容/分值不同的真实TXT/DOCX受控参考文件；提取随字节变化，逐字段依据可对照，不是模拟IPC返回。自然样本质量另记。
2. 编辑/取消无模板和篮副作用，脏稿/来源变化/迟到读取/原请求重试保护；保存v1/v2、两个独立应用及同时应用事务、旧版本不倒灌；原题和实例逐项hash保留，缺额/超额/未映射清楚。
3. 全新与既有v1/v2数据库副本上增量迁移、冷启/跨页/owner权限/伪造输入/学生边界/幂等冲突验证；原D1与Office来源/安装、图文数学/答案隔离回归有效。
4. 同一确认卷单/双栏和不同边距，沿原Pi/目录授权/文件审批实际保存DOCX/PDF。独立核对XML纸张/分栏/边距、PDF页面/内容/答案隔离和截图；取消、拒绝、同名、写入失败、源变化分别记录真实与受控范围。绝不以CSS预览代替文件。
5. 1366×768与1920×1080中真实键盘/焦点、展开/收起、空态/错误/返回、无原生三角和控制台错误；原输入外观不变。模型默认预算0，只有c的原Pi文件验收由父预声明有限发送预算；无自动重发。
6. 每段适用类型/测试；最终build/TSC、renderer-components及关键路径smoke按新改动需要执行。audit、diff检查、截图和原始失败保留，工程/受控真实/自然质量/教师视觉验收分开。包体前后及未测性能如实记录。
7. 正常刷新整合origin/main、保留协作者修改、非强推main/任务分支，并启动固定最新源码构建窗口。资料库、题篮、参考版本、输出与质量证据未齐前，C2和完整Goal保持未完成。
