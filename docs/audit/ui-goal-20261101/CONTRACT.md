## 对话冻结合同

1. 默认只显示公开工作说明和真实工具事实，不渲染私有推理原文，也不将其改名转为公开说明。
2. 公开说明像正文自然流式展开；首次已提交的 `assistant_phase.final_answer` 时整段过程收起，正文继续流式。普通 delta、工具结束、超时不能代替交接边界。
3. 本次交接只自动收起一次；用户手动重开后，后续正文和终态不得再次强制收起。新执行事实仍可见。
4. 顶部过程用时以首次公开活动到正文交接冻结；旧记录缺时间证据则不显示伪精确值。请求等待和正文生成不计入。
5. **工具行及详情均不显示调用用时/排队时间/执行时间**；保留底层遥测字段。工具按真实身份显示图标，可展开已有安全公开内容与来源，不能 dump 原始工具 JSON、凭证、完整本机路径或学生全量记录。
6. 未标记模型回复保留兼容路径，不猜首字边界；该路径不能宣称支持正文首字交接。审批、失败、停止和中断都不冒充完成。
