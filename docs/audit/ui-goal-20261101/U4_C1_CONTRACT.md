# U4-C1 · 从当前题篮补充资料后返回

2026-11-02。用户当前优先需求功能。本切片在 B 已通过真实桌面及六类文件后进行，不替换既有上传、OCR、题本校正、题篮或 Pi Runtime。仅在独立任务分支实施，先完成 B 的 main 交付再修改生产源码。

## 教师结果与范围

老师在已有非空题篮点击“从资料补充题目”，进入现有资料库收录或查看文件，使用原“题目与校正”及题本保存流程。可以明确返回原会话、原题篮和阶段，继续查找题目并点击加入。返回本身不改题篮成员、内容修订或核对记录。

资料 AI 还原完成不等于题目已正式保存。只有现有题本正式记录、当前来源版本和宿主资格能用于加入；取消上传、取消校正或返回均不能制造题目、成功提示或自动加入。

预计写集：`PaperBasketWorkspace.tsx`、`usePaperBasketWorkspace.ts`、`DesktopFrame.tsx`、`App.tsx`、`MaterialsWorkspace.tsx`、`QuestionNotebookWorkspace.tsx`，另可新增一个小型导航交接类型/helper。Astra预审发现题本两个编辑器目前没有导航dirty守卫，因此明确增加 `QuestionArchiveEditor.tsx` / `QuestionContextEditor.tsx` 的最小守卫接入，保护C1返回/历史导航及页内切换；题本新题草稿同样保护。根已批准共用守卫独立为 `QuestionEditGuard.tsx`，避免在 App 或两个编辑器重复实现；生产写集为八个已有文件、两个小 helper。其他扩展先交根 agent 核对证据。

## 状态与受保护消费者

- 导航引用只含 `{sessionId,basketId,stage}`，不携带题面、来源资格、修订、授权或数据库内容。复用应用 history；目标比较须区分两个不同返回引用，不能吞掉同页面的另一个篮。
- 离开前复用当前题篮的蓝图/实例未保存守卫、未知操作结果、锁及 `flushUi()`。拒绝或持久偏好保存失败均留在原页面，不偷偷丢稿；离开入口不绕过 guards。
- 资料沿原 MaterialDraftGuard 保护未保存校正、取消、停止及来源变化。题本的 ArchiveEditor / ContextEditor 现无等效dirty守卫，须在本切片补齐最小接入（可限定C1上下文），并覆盖新题草稿：未保存、保存中、保存失败都拒绝离开；明确取消或保存成功后才释放。页内切换不得绕过保护。带返回上下文时只增加轻量返回操作；普通资料浏览、Pi 来源导航、学生上下文和旧直达不改变业务/数据语义。
- 返回原篮是明确用户意图，重新走既有宿主 owner/basket 读取和授权，不把导航引用当权威。快速切页或迟到 session/hydrate 不可覆盖更新意图；不存在、归档、无权限须明确错误/只读，不自动换篮或重放任务。
- 筛选、分页、滚动和阶段沿原宿主 uiState；冷启继续使用既有题篮引用恢复已保存内容和偏好。应用原 history 仍为临时导航，不新增全模块历史或未保存资料输入的冷启持久化承诺；不得把B旧cold报告当作C1实跑。不要扩展成全局资料草稿缓存或另建持久化真源。
- 显式加入继续用 `expectedSourceVersion + expectedRevision + requestId`，来源变化、重复、归档、权限或分节不匹配仍拒绝。
- 不经 `onAsk` 切换或新建阅读会话；不改 Composer、Pi 生命周期、数据库/preload/host/OCR/模型提示词、vendor、全局样式或依赖。优先使用已有 HeroUI Button/卡片，禁用原生黑三角。

## 验收

1. 真实消费者测试导航比较与上下文接力：两个篮、普通入口、后退/前进、取消、未保存蓝图/实例/校正拒绝，迟到返回不覆盖更新导航。
2. 正式 Electron：从已有非空篮进入资料，实际导入受控文件并在现有题本核对保存；经真实后退/前进和返回按钮回到同 owner/basket/stage，偏好恢复，加入前成员与领域 revision 不变。再明确选择新正式题目加入，仅出现预期变更。
3. 独立 profile 和测试数据副本；不写日常 D 数据、SQL造题或模拟 OCR/成功回执。若只用文本文件，明确不证明自然扫描 OCR 质量。
4. 冷启恢复、上传取消、未保存校正守卫及来源变化拒绝须分别有对应证据；未跑不记通过。1366×768 / 1920×1080 截图、无多重滚动/原生三角、控制台错误检查。
5. 类型、相关 renderer/题篮/资料测试及最终 build 通过；A/B 内容、审批与来源保护不放宽。独立 Astra 审查后修复再验，正常整合 main 并保留协作者修改。
