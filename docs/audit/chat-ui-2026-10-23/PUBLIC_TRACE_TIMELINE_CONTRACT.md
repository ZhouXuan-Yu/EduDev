# 公开过程时间轴补齐合同

用户已确认公开步骤/工具结果/说明、正文流式和完成折叠；样式恢复A之后再次反馈“目前思考链路还是空的”，本片继续完成原需求。组件原设计与固定亮色保持，无新配色/slot覆盖。

根因：现有activity每次覆盖前一阶段；工具和公开说明可持久回看，普通无工具问答则终态没有阶段记录。只连isStreaming不能满足公开过程可见性。

M10修改：共享投影增加可选、限长的publicStages数组（真实stage/since/sequence），消息和工具增加可选traceSequence；仅在收到真实公开事件时记录， renderer按事件序列穿插阶段/说明/工具。最终正文独立，不改变items顺序和assistant分段，不接入私有reasoning、不调用额外模型生成摘要。

兼容：无DDL或IPC权限变化，既有消息metadata增加可选字段。审查后确认旧activity没有持久化，旧记录无法重建阶段，必须明确未记录、不伪造；新记录保存publicStages并校验冷读。缺sequence旧记录保守按原顺序；阶段超过64条提示截断。失败/停止标明最后记录处，不伪装完成；等待教师卡保持外露。终态可选finishedAt提供从首个真实准备阶段开始的处理墙钟，避免切换到SDK-only预算时间而倒退；保存traceElapsedMs，旧记录保守回退原时间。回滚本片投影字段/renderer adapter即可。

验收：无工具普通问题必须有真实准备/等待/生成记录；工具时间轴顺序与公开event.sequence一致；运行中可见、完成折叠后可重开、SQLite事件读回与应用重启一致；旧记录/无计时/重复事件/失败边界，build/组件/专项与正式Electron。只使用亮色1366×768与1920×1080。故障注入必须独立标明，不伪称真实provider事故。
