# 小智基座一期固定验收标准

验收版本FOUNDATION-V1-20261103，执行规则FOUNDATION-V2-20261104，固定24项FAT。冻结后不得增加“不够智能”等开放门槛。本表是基座工程合同，旧产品252条标准保持；独立自然质量/Office-WPS/完整UI验收另列，不伪称通过。

使用明确的合成临时dataRoot与本地受控传输，禁止使用教师原件作夹具。实际生产main/Worker/preload/原Pi链路是真实的，provider替身只控制输出。每项保存输入/源码SHA/运行根/命令/回执/SQLite或文件读取证据；失败保留。旧完全相同且未受影响的合格证据可复用并写明，不能拿低层单元测试代替明确要求的实际文件或主进程路径。

同一模块用一条合成用户旅程覆盖其四项检查，不为凑数重复生成。功能实现后集中跑本模块必要检查；最终集中跨模块回归；未受影响的通过证据复用，失败只定向修复和复测。取消按修复次数中止功能的旧规则，防空转与达标退出见Goal V2。UI布局、颜色与组件风格由另一会话负责，不纳入本期通过/失败。

通用失败判定：不满足任何“必须结果”、未给真实证据、假文件/假回执/丢失已确认数据/重复副作用为失败；缺自然模型费用授权只登记期外未测，不自动打回本期。没有执行的项目写NOT_RUN。
