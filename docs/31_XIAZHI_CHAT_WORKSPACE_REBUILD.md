## 教师可见结果

小智页面采用三栏桌面布局：左侧会话及文件夹，中央对话、真实运行状态和固定输入框，右侧本轮来源、工具活动及待确认写入。当前工作台其他模块仍可从小智侧栏返回；学生错题入口继续进入同一个会话与确认链。1366×768 和 1920×1080 均应保持消息、输入及确认按钮可达。

视觉方向选 Swiss：白色主阅读面、冷灰细分隔、深灰正文和单一蓝色操作色；侧栏使用截图中的浅青底色。焦点是宽阔的文本阅读区与贴底输入，而非仪表盘卡片。页面文字只描述真实会话、来源和操作，不伪造运行步骤。

## 当前事实与复用边界

- 当前 `App.tsx` 已有 typed preload 会话 CRUD、消息回读、模型执行、确认队列和产物预览；页面仍包在 92px 全局导航和带边框的工作台卡片里，AI 区只有会话/对话两栏，信息密度与目标截图不同。
- ZCode `packages/ui/src/v4/SessionPane.tsx`、`ConversationComposer.tsx`、`ConversationRowView.tsx` 与 `WorkspaceSidebar.tsx` 的完整实现依赖其 v4 协议、状态容器、Lexical、国际化和私有 UI 组件。复用其“会话投影、固定 composer、结构化错误横幅与侧栏分组”结构和交互规则；不复制不兼容的大组件。具体可移植的小函数若复制，必须附 Apache-2.0 来源。
- 用户截图是 Codex 桌面端可见页面参考；没有获得该应用的前端源码。以截图还原布局比例与层级，不将截图里的项目、模型或运行内容当成小智真实数据。
- `TypeError: fetch failed` 已在真实 DeepSeek 测试中复现于 TLS 握手前；错误需要在模型网关统一转为可行动的网络提示，保留失败运行、重试入口，不能误报凭证无效。

## 变更面与完成定义

本轮修改小智主聊天页面及局部 CSS，新增右侧运行检查面板，主进程模型网关转换网络异常。会话、消息、确认项、SQLite 表和 typed IPC 沿用现有契约；不迁移真实数据。旧页面结构可由 Git diff 回退，旧 AI 执行开关保持。完成以构建、组件测试、AI/网络错误专项测试、Electron 点击与 SQLite 回读、两种桌面视口截图和 `git diff --check` 为证据。真实 provider 若本机网络仍无法握手，单独报告未验证。

不做通用代码智能体能力、自动执行文件操作、未确认业务写入或对 Codex 私有源码的推测性复制。
