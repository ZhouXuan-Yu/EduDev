## 1. 产品应该交付什么

服务独立教师与小微教研团队。老师提供任务、必要资料和约束，小智理解并持续执行，交付可打开、可修改、有依据的教学成果，并把真实学习反馈用于下一次教学。

第一阶段优先让老师放心把事情交出去；第二阶段把学科正确性与针对性教学做深；第三阶段推广成熟能力。世界领先是方向，现阶段不以模型名称、功能数量、长篇思考或移植源码数量宣称已经达到。

贯穿三阶段的主线：

```mermaid
flowchart LR
  A[明确任务与已有资料] --> B[查明实际可用能力]
  B --> C[准备工具并执行]
  C --> D[打开并核对成果]
  D --> E[交付可编辑文件]
  E --> F[教师使用与反馈]
  F --> A
```

### 工具自动准备的产品合同（新增候选）

- 区分“内置可用、缺依赖、可准备、需授权、不支持、故障”，不能统一告诉模型“没有工具”。
- 技能说明、工具入口、依赖环境、执行授权是四件事。安装SKILL.md不代表安装并接通运行工具。
- 已认可的免费工具在当前任务所需范围内自动准备，固定来源、版本、校验、许可证与占用可读；包与教师数据分目录。新来源和付费服务不能借“自动下载”静默取得新权限或消耗新账户额度。
- 下载不等于允许上传资料、访问全部文件或取得系统管理员权限；已有本地优先与隐私约束保持。
- 新执行包先隔离健康检查，准备失败可清理自身临时内容、重试或用上一个兼容版本；不覆盖教师文件。
- 费用、资料上传、外部发布等动作按真实授权范围处理，不在每一步重复追问已明确的教师要求。菜单只显示宿主真正支持的权限。

### 第一阶段集中试用任务

不扩建大型评分平台。功能完成后用同一小批真实用户路径集中检查一次，保留失败；真实模型使用仍须遵守本任务明确费用授权，旧20次额度已用尽，不从其它知识库任务无限授权借额度。

1. 新会话不选工作目录：一份浮力动态HTML + 可编辑PPTX + 讲解备注；打开文件，操作密度/载荷控件，并核对展示数值和PPT内容。

3. 任务需要的受管工具尚未安装：自动准备后继续；断网/取消/校验不符有清晰状态，无伪成功。
4. 文件生成后触发一次可恢复错误：实际发现并修复；已保存成果不重复覆盖，重启后仍可打开。
5. 生成中继续输入、滚动、停止及拖动窗口；1366×768与1920×1080关键操作可达。

记录完成了哪些要求、真实文件数与打开结果、额外澄清/手动修补次数、时间与费用、失败/未检查项。目标是减少教师返工；没有样本前不承诺固定节时比例或全面胜过Hana。

## 6. 第三阶段：全学科备课（已确认第三顺位）

建议按成熟理科链路扩展：课标/教材版本关联；目标—活动—评价一致；同一目标的分层材料；语文阅读与写作反馈、英语阅读/词汇/语言练习；可编辑教案、课件、讲义和评价量规；旧课件局部升级；教师确认的风格与模板复用。

课标应记录版本与来源，不能只在提示词写“符合新课标”。教师偏好可编辑、可撤销，学生事实只能来自授权学习记录。语言反馈、作业评价先提供依据和建议，不自动作最终高风险评价。

视频/语音、跨应用连接器、周期性备课整理列为后续候选。没有明确用户触发时不启动后台定时任务，不默认增加模型或外部平台费用。

## 7. 共同判断的方法与暂不纳入

每项候选用五个问题判断：是否经常发生、能否明显减少老师返工、是否补足当前闭环、能否复用成熟实现、完成后如何在一次真实任务中看出价值。答案不明确的先做小样，不以数十个新入口替代产品判断。

已确认：阶段顺序、当前先补通用执行、常用工具应可使用且缺少时可自主准备的方向。建议首批：E01–E03，以“真实HTML+PPT交付与连续修改”为锚点，再按依赖继续E04–E08。尚未确认：第一学科/学段范围、新增模型供应商和费用策略、第一批外部工具来源、是否接视频/语音/外部协作。

继续遵守Master：不做学校级平台、学生端/家长端或完整LMS；不建复杂租户/权限体系，不做私有模型训练。后台自主行为、多人/多Agent、市场上所有工具均不因本路线而自动纳入。复用Hana/Pi的源码与设计不等于取得同等模型效果，也不把商业闭源产品当作可以直接复制的源码。
