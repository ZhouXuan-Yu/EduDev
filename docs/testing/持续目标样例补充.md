# 小智持续目标样例补充

2026-10-04；配合根《测试样例说明书》。基础23例、用户问题表和人工签认规则保持。本页新增持续任务场景，不把此前联网/图片反馈标为解决。

## GOAL-01 创建、推进和教师验收

在新测试会话点击输入框上方“持续目标”。目标填写：为教师整理三条互不重复的办公检查项，并给出下一步。验收要求每行一项：三条检查项；下一步具体可执行。

核对公开说明与真实工具过程。目标应先进入“等待验收”，点击验收逐项核对；漏选时不能确认完成，全部选中后才由教师确认完成。模型一句“完成”、工具报告进度均不算验收。关闭自己的测试窗口重开，成果仍在，不能自动重新执行。

## GOAL-02 等待、暂停和恢复

创建目标：先通过实际确认卡询问教研安排是今天还是明天，等待我的选择，再生成两条检查项。到“等待教师决定”时暂停；重启自己的测试窗口。

预期：暂停与进度保留，没有自动新请求。明确点击恢复才出现新执行轮次；需要教师决定时重新确认，不代填或重放旧批准。完成后按GOAL-01审阅。

## GOAL-03 停止、结束与普通聊天隔离

运行中用现有停止按钮停止目标。目标应明确中断，能恢复或结束。另发一条普通聊天，让小智在确认卡等待选择，再结束之前的中断目标。

预期：结束旧目标不会取消或回答这条独立聊天。普通聊天仍可由现有停止按钮停止。重启后已结束目标不复活，不重放文件修改、公开图上传或网页动作。

## GOAL-04 边界与失败

没有进展时应保留已有结果并说明需调整；模型重复同一进度/步骤且无新效果不能无限循环。模型、资料版本、权限或网络不可用要显示对应失败，不把摘要或目标当成授权。文件效果仍按FILE-02/03/04检查真实文件及教师确认；本页文字清单通过不能证明Office文件验收通过。
