## 每个正向案例必须核对

- [ ] 从当前可见页面操作，而非直接调用数据库/接口。
- [ ] 工具完成回执与模型答案一致；失败工具没有被写成“已完成”。
- [ ] 信息来自实际来源/附件正文，不是模型猜测；文件可实际打开。
- [ ] 相同版本、相同保存配置、相同输入的用户问题已重测。
