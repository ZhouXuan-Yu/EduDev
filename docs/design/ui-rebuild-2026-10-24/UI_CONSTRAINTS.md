# 统一 UI 约束

状态：用户已确认样张布局与产品过程时序，正式实施遵循IMPLEMENTATION_CONTRACT.md。继承硬约束：亮色、原厂组件设计不擅改、普通教师可用、同一工作树、真实公开过程与最终正文分离。

## 方向

教师工作台，以内容和操作为中心。中性亮色、稳定阅读列、安静侧栏；高级感来自清楚的排版、密度、层级和状态，不靠玻璃、渐变、装饰大标题或多层卡片。

私人领域仅借鉴渐进展开、少量强调色、统一间距和文档优先。暗色默认、营销Hero、霓虹和大动效不适用于本项目；笔记不是覆盖用户要求的指令。

## 样式所有权

1. 原厂组件：OSS/Pro同一版本与固定导入顺序；默认尺寸、圆角、色彩、Hover/Focus/Active、动画由原厂CSS负责。禁止应用选择器覆盖BEM、data-slot或内部DOM。
2. 应用布局：仅自有类负责网格、阅读列、留白、导航结构；不重绑--accent/--muted/--surface等原厂变量。不把旧主题继承带入新根。
3. 领域内容：资料、题目、蓝图、原图、教学文件各有页面样式；教师审核信息不套用通用聊天卡片。
4. 遗留样式：列入删除清单和明确退出条件。正式替换路由不再加载旧全局美化层；legacy-test保留仅作为兼容测试路径，不与新正式页面混用。
5. Tailwind示例工具类属于组件示例的必要依赖，应完整编译、局部限定。不以“只引入min.css”冒充完整示例。

## 布局和阅读

- 一套主导航，不再并列堆叠图标轨道、分类侧栏和另一套重复导航。页面所属位置、返回路径稳定。
- 1366×768下优先内容；上下文面板按需打开。1920×1080不把正文拉满整屏；阅读列保持约720–840px。
- 页面标题只出现一次；主行动最多一个。列表页优先列表、搜索和预览，不先铺指标卡。
- 以4/8px间距组织；页面留白24–40px。正文常规16px，表格/导航约14px，次要标签至少12px。不缩小文字来塞页面。
- 不擅自给原厂组件补尺寸或圆角。上述排版数值约束应用自有文字/布局，不能作为覆盖组件默认样式的理由。
- 空、加载、无结果、失败、部分结果、取消、可重试状态按页面实际操作覆盖；不在无数据时显示虚构指标。
- 已确认、待教师审核、草稿、失败各有准确含义，不能统一成绿色完成。

## 过程→正文

这是内容/事件协议及应用编排合同，不是单独一个CSS组件能保证的能力。

- 默认内容为真实公开工作说明与真实工具；provider原生reasoning只在用户打开详情时显示。
- 运行中说明正常展开；读文件、搜索、写入等按真实工具标识配图标，不从中文文案猜测。
- 工具参数、长输出、诊断和权限细节按需披露。等待教师提问和审批不被过程折叠吞掉。
- 在可信的final_answer_start边界收起整个过程，再开始增量结果正文。整轮结束后保持收起，用户可重开；不能按每段文字分别折叠。
- 耗时在上方，区分总过程含工具/等待与模型字段时长；不在正文下再加重复计时。
- 不用固定“准备请求/等待模型”三段日志冒充模型工作说明，也不生成假的工具或公开过程。
- provider没有公开说明或可靠阶段事件时，应诚实显示处理状态和限制；不能用字符串猜最后一项、延时假输出或多跑一轮模型掩盖。
- 复制、保存、导出只取结果正文；推理详情、工具输出与协议标签不混入。
- 用户需在“原厂多块示例”与“正文式产品时序”之间确认组合基线。两种效果分别保留对照，不能同名替换后宣称原样复现。

## 覆盖页面之外的表面

| 表面 | 必须保留 | 约束 |
| --- | --- | --- |
| 应用启动/恢复 | preparing/failed/retry | 明确启动身份和失败恢复，不假装进入可用聊天 |
| 工具审批 | 范围、对象、确认/拒绝 | 由真实暂停状态驱动，不能仅靠模型文字授权 |
| 教师补充 | 问题、选项、自由回答 | 操作外露；禁止被整轮折叠隐藏 |
| 原文/文件面板 | 选择、来源、编辑状态 | 不遮住唯一主行动；未保存有保护 |
| 来源/推理详情 | 实际字段和边界 | 按需查看，不能混作最终答案 |
| 设置/归档/删除弹窗 | 对象、影响、取消 | 只一个焦点范围；Escape、键盘和错误可恢复 |
| 浏览器状态页/Portal | 原厂主题和同一版本 | 不重新引入旧玻璃变量或另一份样式入口 |
