# 组卷 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：paper；页面类型：review。

目的：按蓝图选题，审核结构和答案后导出。

默认主要行动：创建组卷任务

## 布局与行为

- 蓝图→候选→审核→导出，显示当前实际阶段
- 总分、题型约束在结构摘要中持续可见
- AI草稿不可直接称成品

## 必须验证

- 100分结构与题目分值一致
- 教师确认后方可交付；取消/失败可恢复

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
