# 我的任务 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：my_tasks；页面类型：overview。

目的：跨对话查看任务状态与待处理审批。

默认主要行动：打开原会话

## 布局与行为

- 任务与审批读取原本地记录
- 打开任务保留原会话
- 从列表进入原任务处理，保留任务与审批的真实状态

## 必须验证

- 执行中、需处理和已确认筛选一致
- 进入原对话不自动发起任务

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
