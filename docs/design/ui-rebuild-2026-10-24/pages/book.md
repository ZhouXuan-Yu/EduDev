# 讲义 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：book；页面类型：editor。

目的：组织章节、修改内容、预览打印结果。

默认主要行动：新建讲义

## 布局与行为

- 章节目录和文档画布稳定，不用多层卡片套正文
- 编辑、预览、导出分工明确
- 预览中的分页与最终文件分别验收

## 必须验证

- 修改章节顺序并保存
- Word/PDF/WPS验收单列，不由网页截图替代

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
