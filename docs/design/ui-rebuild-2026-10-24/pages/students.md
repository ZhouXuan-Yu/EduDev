# 学生档案 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：students；页面类型：library。

目的：查看个人学习资料和教师记录。

默认主要行动：添加学生

## 布局与行为

- 隐私最小展示，不在概览泄露原始图片或整段记录
- 学生详情保留来源记录与教师修正
- 不扩展成学校级管理后台

## 必须验证

- 新增/修改/归档可重启读回
- 原始学生资料不自动上传

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
