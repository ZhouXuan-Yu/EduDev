# 资料库 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：knowledge；页面类型：library。

目的：找到资料、核对原文和解析状态。

默认主要行动：导入资料

## 布局与行为

- 列表和原文预览并列；不以指标卡占据首页
- 解析状态区分等待、进行中、部分失败和可检索
- 来源、页码和教师修正入口与资料同行

## 必须验证

- 导入一份资料→查看原文→查看失败恢复
- 无资料时只有导入主行动

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
