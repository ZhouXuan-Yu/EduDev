# 设置 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：settings；页面类型：settings。

目的：管理模型、资料范围和本地应用行为。

默认主要行动：保存当前设置

## 布局与行为

- 模型/资料/权限/技能/备份分组导航
- 凭证隐藏，连接检查可撤回
- 危险操作说明具体对象和影响

## 必须验证

- 保存、失败、测试连接和恢复默认分别可见
- 不把技术诊断铺到聊天页

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
