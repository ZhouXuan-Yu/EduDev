# 题本 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：question_notebook；页面类型：review。

目的：检索、审核和整理有来源的题目。

默认主要行动：添加题目

## 布局与行为

- 筛选列表与题干/答案/来源审核并列
- 未确认内容显示待审核；答案与解析分区
- 批量操作只在选中题目时出现

## 必须验证

- 核对一题来源、答案并确认
- 列表筛选不丢失已选题目

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
