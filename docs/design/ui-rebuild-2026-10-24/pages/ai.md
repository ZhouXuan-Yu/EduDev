# 问小智 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：ai；页面类型：conversation。

目的：给出教学任务，观察真实过程，获得可用结果。

默认主要行动：发送任务

## 布局与行为

- 运行说明与正文同一阅读列；过程结束先收起，再输出正文
- 工具图标根据实际操作分类；详情按需展开
- 原生推理仅详情；审批和教师问题保持可达
- 只在过程上方计时；输入区不堆任务遥测

## 必须验证

- 公开说明→真实工具→收起→正文，完整观察一轮
- 停止、失败、无公开说明、旧会话重开都可理解

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
