# 学习复盘 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：review；页面类型：editor。

目的：阅读阶段学习反馈并作教师修订。

默认主要行动：生成复盘草稿

## 布局与行为

- 时间范围/依据记录先于结论
- 草稿与教师确认分开
- 教师备注可持续编辑

## 必须验证

- 结论可追到原记录；保存后读回

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
