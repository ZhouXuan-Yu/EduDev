# 备课本 UI约束

状态：用户已批准布局与过程基线；逐页真实业务验收另记。

页面ID：notebook；页面类型：editor。

目的：把资料和教学想法整理成可修改的备课内容。

默认主要行动：新建备课

## 布局与行为

- 目录/正文/来源，主编辑区优先
- 保存状态靠近标题；不重复弹窗通知
- 正文支持撤回修改与来源核对

## 必须验证

- 编辑→保存→重启读回一致
- 离开未保存内容时明确提示

共享状态：loading / empty / ready / running / partial / completed / cancelled / failed / retry。

尺寸：亮色1366×768与1920×1080；不覆盖原厂组件尺寸、圆角、颜色或交互态。
