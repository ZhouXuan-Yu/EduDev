## 4. 设计中演示能力与正式开发的边界

原型只有合成题，文件识别/改编/命题多为显式演示，localStorage 仅用于原型；历史26项证明原型交互，不证明正式服务可用。正式 AI 必须逐项追到已有服务、typed preload、事件与持久事实。

有现成能力就接回；仅缺 UI 投影可做局部适配；缺少领域能力、真实模板提取或导出服务时，登记为阻断依赖。不得用固定样例、假进度或静默禁用来冒充完成，也不得把新 OCR/命题引擎/版式还原列入无期限 UI 任务。缺失必选项按 Goal 的 BLOCKED 出口收束，不自动降低验收标准。

私有推理不作为默认展示内容；只展示公开工作说明、真实执行和产品允许的显式详情。原始资料、数据库、文件权限、Pi 编排、数据真源与保护规则继续有效。
