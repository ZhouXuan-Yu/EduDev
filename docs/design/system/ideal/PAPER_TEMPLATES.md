# 参考卷模板 · 原型增量

本轮只做HTML，不修改正式应用。入口：教学工作台→组卷→参考卷与卷面模板。

流程：导入PDF/Word/图片参考卷→展示提取草稿→核对纸张、分栏、字体、卷头、边距装订线、题型顺序/分值/答题留白→保存模板→模板库修改保存新版本→用于当前组卷或移除。

原型不读取、解析或上传文件内容；文件名用于说明来源，字段是明确标记的演示样例。模板仅在页面内存保存，刷新清空；实际持久保存属于后续实现。应用模板仅展示绑定快照，不实际生成排版，也不自动改变原有题库来源模式。

后续Goal增量：模板保存不可变版本、原卷定位与提取置信项；模板与题源分离；核对题量/分值冲突；编辑使相关审批失效；确认前A4逐页预览、打印/PDF/Word与原卷并排比较，长题、公式、图片、分页、密封线与答案留白分别验收。扫描件须人工校正，不把识别成功等同卷面一致。历史组卷绑定旧模板快照，模板修改不倒灌历史试卷。复用现有文件权限、存储和版本真源，不新造执行器。

Skill增量约束：格式继承不代表原卷题目授权或题目自动入库；不得静默放宽蓝图、挤压留白、溢出页面，或宣称原型实现精确复刻。现有输入框及业务代码保持不变。
