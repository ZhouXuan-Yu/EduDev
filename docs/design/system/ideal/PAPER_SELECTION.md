# 组卷选题原型增量

入口：教学工作台→组卷→下方“选题与出题工作台”。提供题号/题干/知识点搜索，知识点筛选，原题答案与来源详情，手动加入题篮，明确指定某题二改、按教师需求原创，以及保留手选题的默认自动选题演示。题篮支持移除、排序、分值与总分；二改保留父题号和教师要求，生成草稿明确待核对。

仅HTML内存交互：四道合成题、不连接真实题库或模型；原创/二改是占位草稿，自动选题不声称满足实际蓝图；当前题篮与原有整卷快照尚未联动，刷新清空。

后续Goal与Skill验收增量：1. 用真实题号/完整题干/学科年级/题型/难度/知识点联合检索和分页，保留筛选上下文；2. 原题二改精确绑定题目ID、来源版本、图表与教师要求，不覆盖原题；3. 支持指定题数与逐题审核、拒绝/重生成，审批失效规则沿原版本链；4. 手选题锁定，自动补齐剩余蓝图，缺题明示，不暗自换题或放宽条件；5. 题篮必须真正参与蓝图、总分、来源模式、模板和整卷确认快照，不允许旁路导出；6. 题篮离开保护、草稿持久化、并发版本冲突与冷启恢复；7. 生成题答案正确性须教师核对，加入题篮不等于通过审核。先完成原型验收，再排正式应用开发。
