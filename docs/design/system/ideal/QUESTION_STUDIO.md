# 出题与组卷 · 独立工作台原型

本轮确认方案：原教学工作台“组卷”作为入口，进入独立的出题与组卷首页。三种任务：几道题、练习单、正式试卷，共用一份题组草稿。编辑页不再显示教学五页签或旧蓝图、题篮、模板拼接区。全局导航保留。

需求：老师能从题库找题、上传已有题、按需求出题；直接在正文换题、二改对照接受、编辑、移除和排序。少量题不显示目录、不强制考试字段；设置中可转为试卷，保留题目。预览/下载读取同一草稿快照。标题、题序、分值与答案对应当前题组。

技术：question-studio.js负责独立页面与单一内存草稿，question-studio.css负责布局；复用paper-preview.js的预览/打印/HTML下载。替代旧原型render入口，旧模块仅保留历史代码，不再渲染。正式应用源码不改，不新增数据库、IPC或依赖。

边界：题库为3道合成题；上传只演示文件名与一条明确标注拆题；AI出题/二改为占位，非真实模型；参考卷仅绑定意图，尚未提取或套版；刷新草稿清空，当前只保存最近一份内存草稿。真实模板库、知识点配额、自动补题、来源审批、草稿持久化与Word导出仍待后续迭代。旧check.mjs针对旧组卷结构，不可宣称原36项仍适用于新页面。

后续验收：先让教师试用三个入口的最短路径，再完善正式试卷结构和模板；不再追加平行题篮。统一草稿需具有稳定题目ID、来源/父题版本、教师编辑与核对状态；内容变化使相关审核失效，导出前核对当前版本及答案隔离。原型不代表这些生产合同已实现。
