# 出题与组卷 V3：需求与交互约束

2026-11-01，用户确认：取消三种同质模式卡片；以完整题目选题为主界面，选题、编辑、预览可往返。本文替代旧三模式方案；HTML 尚待用户视觉确认，非正式产品验收。

## 老师的工作流程

- 从教学工作台进入，首屏是章节/知识点 + 搜索/筛选/完整题目 + 已选题篮。
- 题库、上传/粘贴、需求命题和参考卷是可组合的题目来源；练习单/正式试卷是交付用途，切换保留题目。
- 已选题可以直接整理成练习，不强制设置考试时间或总分；正式试卷显示逐题分值。
- 编辑时完整显示正文，按需展开答案与来源；编辑、换题、改编后重新核对，未核对内容允许预览但阻止导出。
- 返回教学工作台、继续选题、浏览器前进/后退、刷新均有对应路径。筛选和列表滚动位置保留；新建前归档当前非空题组。
- 原题ID、题组内ID、父题、修订号与审核状态分开。重复加入同一来源题会被阻止。

## 页面与状态

| 页面 | 主要操作 | 空/异常/返回 |
| --- | --- | --- |
| 找题与选题 | 章节或知识点、关键词、题型、难度筛选；完整题目加入题篮 | 空结果可重置，已加入按钮禁用；顶部返回教学工作台 |
| 整理与编辑 | 编辑题干/选项/答案解析，换题、改编、上下调序、用途/版式/分值 | 空题组引导选题，未核对状态可定位，继续选题保留草稿 |
| 上传与核对 | 粘贴按独立分隔行拆题；演示文件识别结果可选择、修改 | 不读真实文件内容，取消不修改题组；题干为空阻止加入 |
| 按要求出题 | 可编辑命题方案，匹配示例题库、仅补充缺项 | 不调用模型，输入不被假装理解；不足明确报告，不删手选题 |
| 参考卷/模板 | 分别沿用命题结构与卷面版式；另存模板版本 | 示例不冒充上传文件OCR；不覆盖题目，不承诺扫描卷像素复刻 |
| 预览导出 | 学生版/教师版、HTML下载、浏览器打印/存PDF | 学生版不含答案；待核对不能下载；返回编辑仍是同一题组 |
| 我的练习与试卷 | 新建、继续、打开归档草稿 | 当前浏览器保存，支持JSON备份；非生产数据库 |

## 当前明确限制

8道合成物理题；学段/学科为固定演示。文件只读取选择器提供的文件名，演示识别使用固定样例；没有OCR/模型/正式题库服务。改编为固定增加理由小问的流程示例。模板仅支持示例命题条目、A4单/双栏，不含真实扫描提取、完整密封线或复杂公式编辑器。HTML下载和浏览器打印可用，Word及服务端PDF导出未实现；实际打印分页需人工检查。

浏览器localStorage保存原型状态，受浏览器文件来源策略与容量限制；换浏览器、换文件路径不保证共享草稿。JSON备份可以下载，导入备份恢复尚未实现。草稿归档最多20份。本原型状态不能迁入生产作为权威事实。
