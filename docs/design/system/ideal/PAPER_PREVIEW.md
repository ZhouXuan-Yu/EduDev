# 当前试卷预览与导出

组卷页“预览当前试卷 / 导出”直接读取当前选题篮快照，展示题序、题干、分值、总分与作答留白；支持学生卷、教师答案卷、答题卡切换。关闭再打开更新快照，空题篮明确提示。

原型实际支持：浏览器打印/另存PDF、下载自包含HTML样卷。未实际打印验证打印机；不承诺Word导出、自动分页准确、套用参考卷模板或正式试卷正确性。生成草稿答案缺失会明确标记，不伪造答案。全部合成题仅供界面审阅。

后续统一页面需让同一试卷状态贯穿选题、模板、预览、审核与导出，替换当前旧蓝图与新题篮分离的过渡原型。正式交付须接原导出链路，核对模板版本、当前题目/来源版本、审批与A4分页；学生卷不可带答案，答题卡与题号一致，教师答案缺失/待核必须阻断正式交付。当前仍未完成独立页面结构重排，不能据新增预览按钮称整套流程已完成。
