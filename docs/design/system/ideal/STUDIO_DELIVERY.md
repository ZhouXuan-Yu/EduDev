## 验收路径

1. 教学→选题→编辑→继续选题→教学，题篮/筛选保留；刷新、浏览器历史仍可恢复。
2. 选择三题直接形成练习，无强制考试字段；预览与下载同一题组，学生版不含答案。
3. 上传识别演示或粘贴题目→核对→加入，与题库题共存；取消不变更草稿。
4. 参考卷分别沿用结构/版式/两者，结果有区别；模板可保存和另存版本。
5. 改编对照确认后变更，修改题干使审核失效，重新核对答案；重复选题不重复加入。
6. 1366×768、1920×1080、窄窗口布局与键盘、空结果、存储失败提示。
