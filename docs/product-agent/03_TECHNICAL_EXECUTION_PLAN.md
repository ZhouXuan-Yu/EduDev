- 普通问答和教学任务在同一 Pi 请求边界补充本轮指导。只投影到模型请求，原生消息、稳定系统前缀与旧 SQLite 保持兼容。识别旧宿主生成的表达块后从历史投影移除，保留教师原文和既有权限语义。
- 构建后用独立本地数据核对跨会话应用、同会话历史、问候、不相关职业问题、本轮要求及无工具路径。验证撤销及重启，保留已有候选核验测试。

### 下一步教师画像与长期偏好管理的现有入口

- `PiCandidateHistory` 可查看、复核与拒绝尚未采用的表达候选，已采用版本仍通过对话撤销。`PiMemoryScope` 管理单会话已明确选中的教育记忆。两处用途独立。
- `createTeacherPreferenceState` 已有当前版本和版本历史，IPC 未提供当前默认偏好的编辑、范围或逐项停用。现有独立数据库可做个人隔离。后续从已授权个人数据根取得身份，验证在设置确认、范围匹配、停用与冲突时的模型实际请求。
