# D3 教师集中验收

用于原执行包《总验收标准》第 6–11 节和《测试计划》的实地验收。当前台账状态为待试用。报名、操作及评分以真实记录为准。工程用例的结果从 [D3 综合验收](08_D3_DELIVERY_ACCEPTANCE.md) 查阅。

## 样本与安排

- 基准为 6 位面向 K–12 学生授课或教研的教师，每人完成组卷、讲义、模考、教案各一项，共 24 个任务。可在原方案的 5–8 人、20–30 项范围内调整。启动前固定任务与名单版本，保留退出和中断记录。
- 以匿名编号 T1–T6 分配角色。教师 Ti 依次完成组卷 Pi、讲义 H(i+1)、模考 M(i+2)、教案 L(i+3)，编号超过 6 则从 1 继续。不同教师各用独立测试数据根。
- 助教提前核对每份材料的使用许可、本地归档版本和基准答案。测试输入登记文件的内容摘要、所属学科年级、可用题目、答案和已知缺项。可替换同类本地资料，替换后的期望结果须在给教师任务前冻结。包含学生信息的材料先脱敏。
- 启动前记录应用提交和主进程哈希、Windows 版本、机器配置、视口及缩放、模型与思考设置。过程尽量由老师独立操作，旁观者只按用例规定补充信息，记录求助、重试和跳过。

## 24 个教师任务

| ID | 教师任务 | 预置资料及通过条件 |
| --- | --- | --- |
| P1 | 用题本原题出一份 20 分钟的高二物理小测，6 道解答题、每题 5 分，覆盖动量、电场和动能三个知识点，各 2 道，先给我核对。 | 至少每个知识点有两道适用的可授权原题及同年级干扰题。核对题量、30 分、时间、知识点、无重复题、原题与答案版本，教师确认后保存。 |
| P2 | 先问我希望给哪个年级，再用题本已有的数学题做一份知识点小测。 | 预置不同年级的同名知识点。宿主从输入框上方等待选定，按选定年级出卷，答案与来源能定位。 |
| P3 | 对比两份已有练习卷，说明题型和分值区别。确认我点名的那份后，只把第 2 题改为 7 分。 | 准备同对话的两份卷。比对阶段保持原文件记录，修订只改指定卷指定题，新版总分可复算，两份旧版可查。 |
| P4 | 从已有原题中组一份基础、中等、较难比例为 1:1:1 的 9 题卷，含选择、填空和解答。 | 事先核对足量候选与三档难度。按教师补充的题型配比选题，难度按题数算，和目标偏差至多 5 个百分点。抽看三题答案及来源。 |
| P5 | 只用指定题集，出一份题集库存不足的原题卷。之后我同意减少至实际足够的题数。 | 首轮库存少于请求。先说明缺口，教师同意后沿原任务提交满足新数量的试卷，登记应有和实有题量。 |
| P6 | 从题本拟卷，做到老师核对整卷时退出应用。重启后继续核对，导出确认版试卷及解析。 | 记录退出前的题目 ID 和计划版本。恢复后使用原任务及题篮，同一明确操作只生成一组文件。核对试卷、答案样式与正式确认版本。 |
| H1 | 根据《等式性质参考》做七年级一元一次方程学案，含重点难点、完整例题和基础、巩固练习。 | 原件有可引用的等式规则。按题验算例题与练习，检查引用可跳到原文，公式可读，讲义可确认和编辑。 |
| H2 | 告诉我怎样给小学生讲分数。随后我指定一个年级和来源，请把建议写成一份讲义。 | 首问作为独立咨询核对无成果写入。第二条开启任务，按选定来源生成讲义，新旧回答的边界清楚。 |
| H3 | 给本章例题保留分步推导，只修改第 2 个练习的难度和解析。 | 准备一章两道以上练习并冻结旧版快照。核对题号、新难度及正确解析，其他例题、章节及引用保留。 |
| H4 | 将已确认讲义导出为学生版和教师版 Word，学生版不含练习答案。 | 对照同一确认版，逐份核对文件名、内容、公式、学生与教师版受众及文件读回。 |
| H5 | 我想备一份复习讲义，先核对缺少的参考或受众，再根据我给的答案继续。 | 一条必需信息未提供。记录追问针对的缺项，补齐后在原任务内继续，最终引用可查。 |
| H6 | 核对讲义草稿后退出应用，重启打开原成果，修改一个段落并确认下一版。 | 比较打开路径、段落、旧版和真实写入次数。原版可查，来源内容一致。 |
| M1 | 整理上海 2025 年初三数学一模，只收录徐汇、杨浦两个区。 | 预置两个同区同年二模、一个其他区一模作为干扰，核对地区、学段、学科、年度和轮次。 |
| M2 | 导入同一份扫描卷的两份拷贝、一份双栏试卷及其答案册，整理目录。 | 拷贝有相同内容摘要、不同文件名。核查文件重复记录、卷号、题目边界、选项归属、阅读顺序和答案版本。 |
| M3 | 归档一套含公式、图表和疑似缺页的试卷，逐项指出需要核对的地方。 | 预先由教研员标注有争议区域与当前页码。检查原页可打开、缺页提示、图表和公式对应，未核验保留待核。 |
| M4 | 这几份同号试题来自两个区，请按来源给其中一套配答。 | 至少一份无答案、一份具跨区同题号答案。核对目标卷的已配及缺失，答案可定位，跨区同题号不串配。 |
| M5 | 把这份已确认的年度目录修正一条分类，再导出目录和原件包。 | 保留旧目录，并准备一份许可不足的文件。核对修订字段、确认版本、出包清单、排除项和文件摘要。 |
| M6 | 年度目录文件组保存后只完成其中一份，退出应用。重开后继续保存缺失文件。 | 用测试目录的同名占位文件制造可控冲突。续做从原任务进入，已经保存的 Word 摘要保持，剩余 PDF 读回。 |
| L1 | 根据两份具名语文资料做一份 40 分钟教案，逐个目标给出活动与评价。 | 资料版本和可核引文预先登记。检查基本信息、教学内容、重点难点、准备、活动、课时、板书、作业、反思、来源与评价。 |
| L2 | 给七年级历史做 45 分钟史料阅读教案，提供两段自拟材料和比较活动。 | 检查两个模拟材料正文完整、清楚标识、可编辑，课堂安排合计 45 分钟，教师核对后确认。 |
| L3 | 修改评价环节第二项检查的题干和判断标准。 | 准备含两项检查的同一教案。核对第 2 项的新题干、判断标准与关联目标，其他检查、活动和课时读回一致。 |
| L4 | 调整 40 分钟教案的导入和练习用时。先让合计出现冲突，再说明该怎么重新分配。 | 第一条特意让总时长不符，检查具体差值及版本。第二条明确两个环节用时，原任务保存合计为 40 分钟的新草稿。 |
| L5 | 把已确认的同一版教案交付可编辑 Word 和 A4 PDF。 | 检查教案版本、关键正文、活动和评价，保留两个文件的哈希并确认两种格式可读。 |
| L6 | 有两份教案时请小智先让我选。等候选择时退出，再重开完成其中一份的局部改稿。 | 核对恢复入口、原会话和目标教案。只在明确选定后写入下一版，另一份教案历史可查。若无法继续，记录实际中断状态和阻塞。 |

## 计分与原始记录

| 指标 | 计入分母 | 计入分子 | 目标 |
| --- | --- | --- | --- |
| 意图识别 | 每份任务首次有效发送，以及 H2 的独立咨询 | 预先登记的问答、生成、修改、导出或恢复目的与实际入口一致 | ≥95% |
| 必要追问 | P2、H5、L6 的必问点，以及登记在替换资料中的其他必问点 | 问到该缺项并经真实界面得到回答后继续。另记已明确条件的重复提问 | ≥90% |
| 多轮上下文 | 预先登记需延续原 Task、源成果或已确认约束的后续请求 | 保留正确 Task、成果 ID 和仍适用的限制 | ≥95% |
| 修改正确 | P3、H3、H6、M5、L3、L4、L6 的实际修改指令 | 修改指定字段且邻近字段、旧版本及来源经实际读回正确 | ≥95% |
| 核心完成 | 有效分配且开始执行的任务 | 逐条达到该任务的通过条件，保存、导出和副作用可读回 | ≥90% |
| 恢复成功 | P6、H6、M6、L6 的预置退出场景 | 恢复到原任务或由原入口安全继续，核对既有产物及写入次数 | ≥95% |
| 讲义采用 | 完成并交给真实教师核对的讲义 | 教师判定可以直接使用或只需轻改，同时交出具体改动及耗时 | ≥80% |

所有比例记录为「通过数 / 有效分母」。未执行记为未测，同时报告覆盖；执行失败继续留在对应有效分母内。样本较小时保留实际计数，无分母时暂不计算。

建议在本地逐任务填表，保留原始记录并由另一位能核对该学科的评审签记。计时从首个发送到可用成果，另外记录等待确认和主动编辑的时间。修改用时为从打开编辑到结束修改的实际时间。采用判断分为直接用、轻改可用、需重做、拒用；轻改限文字或版式微调，教学事实或解题逻辑重做单列。版本、题目、来源以应用记录和实际文件为准。

```text
评审批次,任务ID,教师匿名ID,应用SHA,设备与视口,模型与思考档,资料版本清单,开始时间,结束时间,主动修改秒数,等待确认秒数,返工次数,会话ID,任务ID,成果ID及版本,意图结果,追问结果,上下文结果,修改结果,完成结果,恢复结果,采用类别,人工核验明细,文件哈希与截图,评审人匿名ID,未测或失败原因
```
