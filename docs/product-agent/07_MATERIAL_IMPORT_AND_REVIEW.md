# 资料导入与试题核对方案

## 导入与整理

资料库保留文件多选和整目录快捷导入。需要挑选文件时选择「从文件夹勾选导入」，在包含子目录的清单中选择所需文件。在确认前，后台只发现文件及其版本。确认后沿原队列复制原件、收录正文和恢复本地结构。清单支持全选、清空和跨页勾选，关闭后可在处理队列重开待选批次。跨重启保留批次和发现结果，未提交的勾选会重新选择。

本地收录和 AI 整理是两个可独立操作的阶段。资料详情的「开始 AI 整理」打开原范围及授权表单。整批 AI 整理仍可从处理队列打开，只覆盖本批实际归档的资料。

Lightroom Classic 的导入先展示来源和待选项，再提交选中文件。Power Query 从目录选文件时先看清单，可按扩展名、文件夹路径筛选，再处理。小智采用明确的候选与提交边界，后续筛选规模根据批量使用实测决定。 [Adobe Lightroom Classic](https://helpx.adobe.com/in/lightroom-classic/desktop/import-photos/import-photos-video-catalog.html) · [Microsoft Power Query](https://support.microsoft.com/en-us/excel/import-data-from-a-folder-with-multiple-files-power-query)

## 题目核对布局备选

资料详情当前在同一分区纵向装配本地结构、按题图文、题册关联、AI 批次和 Word 整理。结构页同时渲染本页多道题的正文、选项和图表。这让老师切换题号后仍要在狭窄长栏寻找当前对象。下面三种布局均以原件为凭据，保留现有题目、来源、异常与教师草稿。

| 方案 | 老师怎样操作 | 适合场景 | 取舍 |
| --- | --- | --- | --- |
| A 题号列表和单题工作区，推荐 | 左边显示题号、页码和待核原因，右边只显示当前题。顶部固定上一题、下一题和只看待核。可切换原图与识别稿，宽窗可并排。 | 导入后快速浏览并校对，常在相邻题间切换。 | 离开题目后保留筛选与滚动位置。跨页题用来源页码跳转。 |
| B 以原卷为主的双栏 | 左边是整页 PDF 或图片和页码缩略导航，右边固定显示当前题面、答案和证据。选题时跳到原文并标出区域。 | 扫描件、双栏试卷、图表和跨页题，教师习惯翻原卷时。 | 窄窗口需要在原页、当前题之间切换。定位失败时仍能查看原页。 |
| C 只查疑点的逐题工作台 | 从待核入口进入，逐题展示疑点、原图和候选。完成一题后可前往下一个疑点，进度显示已核与待核。 | 大量试卷，只抽查异常。20 道题有 2 道疑点时，默认核这 2 道。 | 适合作为 A 的快捷入口。遇到需要通看全卷的情况，可返回全部题目。 |

Windows 官方列表—详情模式在宽窗并排、窄窗单视图并支持返回列表。Acrobat 用缩略图和书签定位文档页。Gradescope 把当前原题与核对动作放在同一工作面，底部可切换工作对象。这些模式对应 A、B、C 的主要交互。 [Windows 列表和详情](https://learn.microsoft.com/windows/uwp/design/controls-and-patterns/master-details) · [Adobe Acrobat 缩略图与书签](https://helpx.adobe.com/acrobat/using/page-thumbnails-bookmarks-pdfs.html) · [Gradescope 阅卷](https://guides.gradescope.com/hc/en-us/articles/22248789286157-Grading-Homework-Problem-Set-Assignments)

建议先实现 A，安排 C 的「继续核对」直达。B 作为原页对照模式。正式版式待选型。

## 布局验收条件

- 连点 20 个不同题号，页面始终只挂载当前题的重内容，操作区位置稳定。列表只滚动导航内容，切题后归位于新题标题。
- 筛选「待核」后只显示实际疑点。状态列可区分已识别、待核和教师确认。返回列表保留筛选、题号、滚动和原页定位。
- 当前题的题干、表格、公式和答案在 1366×768 与 1920×1080 都能查看。宽窗可并排看证据，窄窗可切换视图。
- 草稿中的修改须按原规则保存或显式处理。快速切换、审阅时来源刷新、跨页跳转、重启后均核对题目与证据归属。
