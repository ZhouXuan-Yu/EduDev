## 教师与规模集中验收

| 指标 | 原目标 | 统计口径 |
| --- | --- | --- |
| 意图识别 | ≥95% | 独立评审员按预先写明的任务意图逐条比对。分母为每个首次新建请求和独立问答。 |
| 必要追问 | ≥90% | 分母为预先标注缺失必要信息的任务；另外记录已具备条件却被重复询问的次数。 |
| 多轮上下文保持 | ≥95% | 分母为要求保留同一任务、已有约束或精确成果引用的后续轮次，检查 Task 与成果 ID。 |
| 修改正确率 | ≥95% | 分母为明确的局部修改任务，比较指定字段与相邻字段的前后差异。 |
| 核心任务完成率 | ≥90% | 分母为分配给教师的组卷、讲义、模考、教案任务，副作用以写入与读回为准。 |
| 恢复成功率 | ≥95% | 分母为预置中断任务，要求从原 Task 恢复并核对先前文件摘要，无重复效果。 |
| 讲义采用率 | ≥80% | 分母为交付讲义的试点任务。由独立教师记录是否可直接使用或只需轻改，并保留用时。 |

按原标准建议招募 5–8 位目标教师，分配 20–30 个代表性教学任务。分别记录鼠标与键盘操作、交付时间、修订时间、返工次数和采用结果。工程师操作和模型评分单独标记。另以真实硬件记录冷启动、恢复、文件导入、OCR 队列、长对话、大成果与存储增长。性能窗口、样本构成和设备信息随原始数据留档。
