本轮按冻结主线迁移 v4 之后新增 v5。保留此前迁移、账本、备份和旧会话协议。对现有真实数据使用兼容构建升级前需先保留恢复点。回退时使用该构建对应的升级前副本，原升级库保留，禁止手改数据库版本。
