## 2. 纵向范围

- shared：严格公开图工具参数和private utility model-image.v1；image_delivery安全事件，现有Office tool projection新增可选receipt，不改变旧schema。
- main：附件importer增加main-only已capture图片字节入口；原utility加入model用途分支，主进程不解码；原Hana450 normalize/prepareSingle/原Pi resize复用，不改vendor。
- 独立public-image runtime：只submitted当前session/revision/version/hash、真实user message/run、未归档；必要purpose脱敏，fresh官方目录图片能力；通过原ask_teacher持久question/typed回答确认，自由文字不能代替指定明确选项。原once/execution/cancel保持。
- Pi：仅受控媒体runtime存在且官方已知图片模型时注册image，每请求过滤无当前授权的旧image；摘要无原图，旧native只本地保留；实际onPayload最终逐图重核当前authority/MIME/SHA和单请求大小，native stream结果收到有效response才记received，错误/停止不伪回执。新增独立capability identity，不改旧creation/模型/技能/记忆。
- UI：复用原question卡、ChatTool/Group/Sources；准备工具与送达事实分开，等待/发送/接受/失败可见，无隐藏推理/raw bytes/路径/hash展示；后续D4才核完整查看计数/缩略图统一。
- 相关native Electron、正式renderer/原Pi/官方DeepSeek实例，独立build/owned profile/旧native副本；不维护真实profile、不重写用户运行out。

## 3. 权限、兼容与恢复

确认明确当前图片是公开资料且不含学生信息；无此声明拒绝发送。只本轮用途有效，停止立即取消；冷启动/新run不自动送旧image或恢复授权，必须新工具调用与新确认；已发信息不能冒称可撤回。摘要/历史/模型文字不授权。不把模型换成辅助视觉API，不上传学生原图/原库。

SQLite沿原controls/events、附件和message/run事实，无新表/迁移；旧native原字节prefix保持，仅追加独立identity与实际tool image。旧cache未知modalities在原resolve补刷新，不猜模型能力；模型物理容量/单请求/单工具限时和payload护栏保留，不设累计模型/工具/token/运行预算。Base64传输大小与真实图片token估计分开，不能把base64字符当token导致误压缩/拒绝。

功能回退禁用publicImage runtime并拒绝含其identity的新调用；旧图片仍本地可查看不再上传，原OCR/文字/浏览器继续。退出/停止finish receipt失败或中断，pending question原恢复规则不自动发图。
