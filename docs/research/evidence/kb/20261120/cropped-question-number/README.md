# 原件裁缺题号的结构恢复

## 根因

U16 习题课第 2 页的首题原件已裁去题号。冻结 OCR 保留了题干，手写数字和演算被识别为额外段落。旧版把这些段落和独立题干组成同一条缺少起点的候选，教师审核入口拒绝处理。下方的「第 6 题图」被父题识别器读成新题，A–D 选项被截断。第 3 页的显式新例题也被续接到第 6 题。

## 修改与旧数据

- `material-document-structure.ts` 使用分块、几何距离、单页同栏、完整问句和明确的相邻父题定位独立题干。派生候选保存题干原文与坐标，其他原始数据留在页回执。题号未知仍标记待核。
- 同文件识别独立编号图注，只有图片匹配唯一时才保留图注的所属锚点。完整 A–D 题后遇到下一页显式例题时，结束原题的跨页候选。
- `material-document-structure.ts` 的共享合同升级为结构 v8，保留 v2～v7 读取。无 SQLite 字段变动，旧派生版的重建继续走已有入口。
- `MaterialStructurePanel.tsx` 和 `MaterialStructureReview.tsx` 显示题号待确认，复用来源确认、单页原图和教师修正保存。教师认定的纯文字题干与原始图片证据分别留存。
- `document-structure-boundaries.mjs` 和 `document-structure-electron.mjs` 增加合成反例与真实原件验证路径。处理和验证均在本机，模型调用为 0。

## 测试与性能

- `node --experimental-transform-types scripts/education/document-structure-boundaries.mjs` 40/40。
- `npm run test:renderer-components` 253/253。
- `npm run build -- --outDir test-results/build-kb-cropped-number` 通过。
- `npm audit --omit=dev --audit-level=high --json` 报告既存 23 项通告，其中 8 项 high。依赖无变更。
- 该单份 5 页原件的实页后台基线用时 170.31 秒。首次 v8 同机重导用时 71.43 秒。两次是不同时间的完整 OCR 与布局流程，包含运行时冷暖差异，不能用于推定吞吐变化。
- 原通用实页测试要求至少自动入库一题。该原件在两个版本下自动入库均为零，两次运行保留为失败。专项模式改为明确检查这份样本的待核原因与教师人工确认；通用自动入库断言继续保留。
- 桌面实页已保存一条经来源确认的教师修正。SQLite 回读证明缺答继续保留。保存后测试定位使用了已卸载的编辑容器，冷启复测结果另行记录。
