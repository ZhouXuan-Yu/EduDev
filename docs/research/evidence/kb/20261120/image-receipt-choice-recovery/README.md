# 迁移后复核已有图片题

## 根因和修复

备份恢复会复制原图并重定位资源路径。原图 SHA-256 没变，记录中的设备、文件身份和时间戳仍对应旧目录。旧版历史验证只允许 Word 和 PDF 在这一条件下重新认证，图片页仍按派发时冻结的物理标识检查。资料页的图片预览还有一次同样的严格检查，选择题复核也直接走了派发侧的标识要求。

- `material-ai-repository.ts` 为已保存图片页复用历史 PDF 的完整文件哈希校验。原件、页来源、正文和已存模型输入继续逐项核对，预览重新读取保存的图片时还与回执摘要对照。选择题复核与版式复核共用取消、超时和事务提交检查。批次准备和模型派发继续使用冻结的物理标识。
- `material-ai-choice-rechecks.ts` 把取消信号传到原件和裁图读取。提交复核结果前再次认证原件及裁图，比较当前物理标识。原件在同一次事务中变化时撤回题目和复核记录。
- `kb-choice-answer-boundaries.mjs` 验证复核期间文件身份变化时回滚，以及已取消操作不读写。
- `kb-saved-choice-recovery-electron.mjs` 复制已有试导库，经正式重定位函数恢复，以教师资料页的现有按钮复核，再使用桌面版题库检索、组卷与确认接口实测。测试完成后保留隔离数据根用于后续整库评估。

## 修改前后

| 检查项 | 旧构建 | 本次构建 |
| --- | --- | --- |
| 同一物理批次、同一试导库的历史原件读回 | UI 提示原件或正文已变化，不能复核 | 显示已存输入图，图像摘要与回执相符 |
| 已存选择题复核 | 0 道恢复 | 3 道进入可用题库，2 道保留待核 |
| 初三物理短卷，仅限原题 | 0/3 | 3/3，共 15 分，正式确认后可重启读回 |
| 调用次数 | 新增 0 | 新增 0 |

三道题的题干、选项、答案、解析和冻结响应逐字节保持原结果，复核只更新归档状态。两道待核题的记录保持一致，未将选项文字冲突或其他实质差异当作格式问题。此次复核证明已存的两次答案表示与原选项相符，独立答案册核验另行计入验收。既有 Word 复核记录继续保留。合法迁移批次的教师操作用时约 206 毫秒，含界面反馈。旧构建直接拒绝该操作，无可比成功耗时。

整库隔离副本有规则初稿 3,082 道，AI 待核 97 道，AI 定稿 21 道，教师编辑 2 道，尚无独立答案册配对。归档状态计数和完整蓝图可用题数分别统计。待核题中，80 道仍带题面不完整问题。

## 下一处批量断点

隔离副本中有 15 个已保存原始响应、仍因无效响应中断的 PDF 页单元。现有本地响应恢复只识别 Word。5 个末轮失败页的首稿和局部复核均无题，末轮突然新增 8 个候选，应继续拒绝发布。下一轮先验证其余首稿回执能否满足冻结的版面和字面校验，再接入可恢复的页级工作，并在三方题数矛盾时结束无效派发。8 个被拒候选未计入可用库存。
