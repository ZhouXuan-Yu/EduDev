本轮只读盘点已保存的试导库。数据取自该库的现有快照，包含不同阶段的历史产物。生产静态判断复用 `archiveEligible`、题目身份检查和文档完整性判断。

## 已修复的两个通用缺陷

| 场景 | 原结果 | 本轮结果 |
| --- | --- | --- |
| 质量模式有已授权的配对答案 PDF 正在等待本地解析 | 优先分支结束当前调度，其他可运行资料也等 | 配对题本等自己的答案册，独立就绪资料可以继续。答案可处理后恢复优先 |
| 已写回答案的题目或答案依赖前页卷名，另一本资料有索引待办 | 读取已归档题时返回来源未就绪 | 按题册和答案册各自版本检查。相关待办、删除原页和本册重建仍阻止读取 |

修改文件：

- `material-folder-ai.ts` 复用轮转游标与单子任务授权，按已发现的配对依赖选择就绪材料。
- `material-book-answer-index.ts`、`material-book-question-section.ts`、`material-book-answer-repository.ts` 将已存配答读回的待办检查限定到两册版本。复用原索引、回执和已删除页的替换记录。
- `kb-folder-ai-boundaries.mjs`、`kb-section-inheritance-boundaries.mjs`、`kb-answer-section-boundaries.mjs` 覆盖旧行为复现、等待关系、迟到解析、不同资源及版本、相关待办、删除、重建、冷读。
