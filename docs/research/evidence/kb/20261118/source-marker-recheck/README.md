# 有来源编号的版式误判修复

## 根因

原双栏 PDF 的本地段落、补缺选项和 AI 首稿已完整。已保存的两份独立来源转录分别使用 ASCII 与全角句点，如父题号“1.”/“1．”、选项“A.”/“A．”。source-layout-text.v1 只处理汉字排版空白，readingBodyComplete 的 marker/body 严格比较和 pageFragmentsAgree 的题面比较因此失败。四题只有整页待核引用，未生成完整题文档。旧字面比较必须保留，不能直接用 NFKC 放宽数学、单位或其他标点。

## 实现与修改清单

完整修改路径及原始工作树摘要见 MANIFEST.json。

- 新共享 source-layout-markers.v1，仅用于 comparison copy。要求冻结的 source-layout-text.v1、内容角色和同页结构上下文。按原 parent/option 段落确定题号和选项，完整段落正文须能绑定。
- 父题号限同题开头或独立 marker 角色；选项须为原 A 开始的连续 A-H 标签，每个标签在候选中恰好出现一次且顺序一致。只归一 ASCII/全角点号。缺行、重复、低分、结构疑点或绑定失败时保留严格比较，不采用模糊匹配。原 OCR、条件、模型正文、角色和图片均不改写。
- sourceLayoutQuestion、裁块完整性、独立来源 body/marker 比较、字母答案对照接通新策略；公式/表格/独立图中文字沿原规则。独立图像模型输入移除新编号策略与结构提示，保持独立。
- 新 quality 输入按批冻结新策略。旧批次经原“复核来源版式（无需模型调用）”动作和 writer 事务应用；复用 material_ai_choice_rechecks，保存版本、原归档和证据摘要。一个动作总上限仍为20条。教师编辑/收藏/分类/使用题不被覆盖，旧 v1 审计继续重算认证。
- 冷读按原页、原裁图、原输入/回执和审计重算 before/after。无新表、IPC、依赖、模型服务或页面布局改动。
