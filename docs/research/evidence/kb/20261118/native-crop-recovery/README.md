# PDF 原生定位与局部 OCR 补缺验收

## 根因与修复边界

前序段落和试题结构恢复已经从 OCR 行、PP-DocLayoutV3 区域与坐标重建段落和完整题目，并对缺失选项的候选保持待核。实际双栏样本打印了 16 个选项，整页 RapidOCR 只返回 15 个。缺少的 C 行从未进入原始行数组，因此后续合并段落无法恢复它。此前教师只能对照原页手工补齐。

本轮增加 PDF 原生文字定位与原页裁图 OCR 一致性检查，接在 material-structure-runtime 的整页 OCR、页面区域及原图保存之后，位于 recoverStructurePage 之前。源文字仅定位缺行，选中补充文字必须来自当前裁图的真实 RapidOCR 回执。原整页 OCR rawText、原始行身份和坐标保持。

原始局部裁图同样未能完整识别“六米”。首轮真实测试保留失败并保持待核。固定的有界纵向归一化与白边处理后，实际局部 OCR 完整识别出该行，置信度 0.98881，并与 PDF 原生文字逐项相符。图像处理规则不读取答案，不使用出版社、文件名、题号或特定汉字条件。

另外修复两个衍生问题。插入缺行会改变段落序号和题目派生 ID，旧教师题和自动题可能被重复入库，现以物理原 OCR 来源身份查询既有所有者。原生文字层还可能包含整页 OCR 未读到的个人信息，现将其纳入原页隐私判定，并保存独立源块。

## 实现与修改文件

完整文件清单与 SHA-256 见 MANIFEST.json。

- material-native-text.ts 定义 xiaozhi.pdf-native-text.v1 私有 Worker 协议和 pdf-native-crop-concordance.v1 证据。新 Worker、host 和 reader 复用已锁定的 unpdf 1.8.1 / PDF.js 6.1.200，原 PDFium 页面渲染继续使用。
- reader 采用 64KiB 范围读取，单页最多读取 64MiB、4,000 原生项和 128,000 字符。原文件身份在前后检查，Worker 有超时、取消及有界错误。PDF 原生项保留原文、变换、大小和归一化区域。
- material-native-gap 只处理不与现有 OCR 重叠、属于正文区域的整行缺失。页眉、页脚、图片和公式区域排除。每页最多 8 个候选，每个最多原图及固定纵向归一化两次读取。高置信度冲突直接待核。
- 新增行使用真实裁图 OCR 文本。安全比较复用既有 sourceLayoutSignature，保留负号、数学运算、上下标及拉丁/数字内部间隔，仅统一已有排版空白与选项前缀标点。原文、原裁图、处理图、摘要、置信度、页码、坐标和全部回执保存到派生页。
- material-document-structure 的派生引擎升级为 layout-paragraph-question.v2。原 schema 与旧归档读器兼容，历史派生页保持，新导入默认应用，旧资料显式重建生成新代。未确认缺行产生 native_unconfirmed，自动归档保持隔离，教师仍可沿原显式来源核对修正保存，原疑点与核对回执分别保留。
- material-structure-identity 和原结构仓库复用既有来源成员与归档记录，按原 OCR 行、原图摘要及资源版本识别旧所有者。段落重排不会重建教师事实或重复入题本。查询分页及本地页缓存有界。
- db.ts 的原页隐私检测同时覆盖原生文字，既有来源块及偏移保持。界面在原结构面板显示补充行数与待核行数，原来源及教师修正映射继续可操作。
- 新增原生边界、范围读取、真实局部补缺和自然 PDF 验收脚本。原双栏测试拆出同一受控 HTML 夹具，分别记录整页 OCR 与补充后的选项数量，避免统计口径混用。

生产依赖及锁文件无改动，复用现有组件。新增一个本地 utility 构建入口，新增模型调用 0。

## 失败与未解决项

- 首轮局部 OCR 仍漏字，真实 E2E 失败及其完整候选快照保留。固定归一化处理接入后按相同条件通过。没有将失败候选人工改成自动通过。
- 代码复查发现初版把未确认缺行同时设为人工保存阻断，已移除这条额外限制。新增专项证明自动准入保持拦截、教师显式保存可用且原疑点保留，组件同步覆盖。修正后的完整构建和用户路径另按最终树验收。
- 初版预算测试有一个合成缺行坐标与既有 OCR 重叠，候选数预期错误。保留失败日志并修正夹具坐标，限额断言保持。
- 初次构建遇到 PDF.js 6 类型接口变化，调整范围传输参数后完整构建通过。早期探测误用 document.destroy 的输出保留，正式 reader 使用 loadingTask.destroy 并关闭文件句柄。
- 显式重建保留已归档题目的原题面与教师修改，新增补充行进入新派生结构。旧自动候选如需补齐，仍需从原题本对照原页编辑。本次旧漏行题已有完整教师修正，新导入直接使用补全后的候选。
- 当前补缺限定原生文字层可定位的整行缺失。行内错字、完全扫描件漏行、旋转或竖排文字、复杂公式和表格语义继续依赖原图及后续核对。扫描件仍可能待核。
- 单页超过 8 个缺行候选以及低分、冲突候选保持待核。置信度阈值和双证据一致性仍有识别局限，本轮没有证明任意出版社题库全部无误。
- 新补充行尚未接入旧的 DeepSeek 页级冻结输入，独立 AI 结构核验和后续 AI 来源契约接续为下一切片。历史付费输入保留。
- 原整库自然质量、Word 题答联动、联网补答、完整检索组卷、安装/迁移与约 10GB 仍 OPEN。完整知识库 Goal 保持 ACTIVE。
- npm audit 35 项，其中 high 15、critical 0。生产依赖未变，既有 Python 审计工具缺失问题仍未解决。

## 验收结论与回滚

本轮整行漏识补缺切片通过定向验收。前序 P0 段落/试题恢复结论见同日 ocr-document-structure 报告，本轮原有结构、持久化、教师修正和主要业务回归通过。P1 复杂版式与独立 AI 核验仍为部分完成。

回滚先备份数据根，再停用 nativePdfText 与 recoverNativeGaps 的新导入调用，保留 v2 派生页、补缺回执、来源身份及旧归档读器。新代可按源文件重新生成，原资源与教师题目继续保留。旧二进制直接读取 v2 派生数据尚未验证，不能用删除证据或修改教师事实实现降级。
