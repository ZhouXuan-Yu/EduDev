# 本地结构证据接续 DeepSeek 验收

## 根因分析

本轮核对实际已导入的双栏 PDF。material_pdf_pages 的 text/nativeText 已含 C 选项，不能据此判断 AI 的版面提示也已完整。registerMaterialAiIpc.blocks 从原整页 OCR 生成 blockTexts，该 OCR 只有 15 个选项。本地结构 v2 已通过局部复读补回第 16 个选项，但 MaterialAiRepository.localBlocks/pagePreparation 未读取这份证据，输入冻结和 provider 首稿收到的块级提示仍缺 C。

首次真实 AI 批次进一步暴露答案格式缺陷。首稿四题分别答 D/B/B/B，末稿相同字母后附加解释。已有 PRINTED_CHOICE_ANSWER_INSTRUCTION 位于 provider 条件表达式的普通分支，独立 literal 复核分支只收到“写完整结论”，导致四题触发严格 answer_conflict。本轮为新批次冻结 printed-choice-literal-answer.v1，明确嵌套 answer.text 只填写选项字母，解释写 analysis.text，原比较规则继续严格执行。

## 修改文件与实现

完整路径和工作树 SHA-256 见 MANIFEST.json。

- material-ai-structure.ts 定义可选 xiaozhi.ai-structure-source.v1。复用 StructureParagraph，保存段落顺序、原文、坐标、置信度及疑点，补充行绑定原页、原始 OCR 摘要、局部图片和 OCR 回执摘要。每份上下文最多 32KiB。
- material-ai-structure-source.ts 读取同资源版本、同页、同栅格的已完成 v2 派生页，核对原 OCR 行和页摘要，使用 QuestionAssets 验证实际 PNG，再以已有 recoverNativeGaps 从原回执重算一致性。原始裁图和处理图的关联也受认证。读取单份派生 JSON 上限 4MiB。
- 补充后的提示按恢复段落的 lineIds 顺序生成，确保 C 在 D 之前。新增输入和冷读均验证 blockTexts 与这份同页证据一致。历史 generation 在新结构重建后仍可认证。
- MaterialAiRepository 在新 standard/quality 输入中接通这份来源，复用原批次、writer、预算和任务机制。新输入冻结引用，发送前和来源读取时重新认证，段落文字沿原学生信息脱敏器检查。旧无结构资料及 legacy 输入继续原路径，历史付费输入保留。
- MaterialAiProvider 首稿获得段落和补充行说明。independentLiteralContext 从独立原图转录中移除结构文字、OCR 提示和 material，实际请求观察证明后续阶段只收到其原协议允许的信息。
- 新的 literalChoiceAnswerPolicy 按批次冻结，独立末稿采用嵌套角色对应的选项字母规则。缺少该字段的历史输入使用原策略，原付费结果继续认证。
- aiPageQuestionIssues 和转录状态保留未确认缺行。末稿遗漏已由局部 OCR 确认的文字、漏掉所属题或把该选项只写进其他题时，对应候选保持待核。比较复用既有安全文本签名和本地段落 marker，没有回写模型文字。
- 原 AI 页详情显示本批使用的段落与补充行数量，沿 typed preload 的既有 AiPageView 返回。未新增 IPC、表、生产依赖、模型服务或自动上云授权。

## 失败与未解决项

- 初版补充行直接追加到提示末尾，存在 A/B/D/C 顺序错误。增加顺序断言保留失败后，改为复用恢复段落顺序，最终通过。
- 首次类型检查有 unknown 文本缺少类型收窄，修正后完整构建通过。
- 测试观察器初版在 Electron evaluate 中动态 import 失败，改用 Node 内建模块入口。随后测试夹具误用另一运行时保存的密文，原设置接口通过已有环境密钥恢复。两次均发生在新批次创建前，0 计费调用，失败证据保留。
- 首批实际响应暴露独立末稿答案格式指令遗漏，本轮已通过版本化新输入修复，最终再次真实调用验证。
- 读回脚本起初将待核裁图与整页输入图作摘要比较，之后又直接比较 SQLite 空原型对象与 JSON 对象。按真实裁图回执及精确 JSON 字段修正断言，原失败保留，最终四图和全部付费字段通过。
- 最终四题仍有 missing_grade。该样本没有印刷年级，AI 保持空值，需要教师补充。
- 最终来源稿采用“1.”、“A.”，末稿采用“1．”、“A．”。逐项检查确认补充行没有丢失，现有严格比较仍给出 ai_mismatch，四题继续待核，尚未形成 complete 题文档。题本可读取原选块的待核裁图。下一步基于这批已存响应，做有来源边界、版本和审计的标点版式核对，保留数学符号、小数、上下标、单位和原文，复用原本地来源重核动作，优先 0 新调用。
- 独立结构核验的广泛自然质量、跨页补充证据、复杂公式/表格、题答联动、完整检索组卷、安装迁移及约 10GB 继续 OPEN。
- 本轮没有外部教师人工验收。npm audit 共 35 项，high 15、critical 0，生产依赖未变。

## 验收结论与回滚

本轮来源接续与新批次答案格式切片 PASS。真实模型验证保留四题待核结论，完整知识库 Goal 继续 ACTIVE。

回滚可停止新输入的结构上下文和 literalChoiceAnswerPolicy 构建，保留 xiaozhi.ai-structure-source.v1 的来源认证、已写入的可选提示读器、历史派生页、原始图片及模型回执。SQLite 与原文件继续为事实来源。旧二进制直接读取新增提示字段未经验证，须先备份数据根并验证兼容读器。
