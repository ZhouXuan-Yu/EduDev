# 结构题的独立题图进入正式组卷

## 根因与修改前后

文档解析已经为题目关联页内图片区域。题库归档只保存整段题面截图和按字母裁出的选项图，普通装置图仍在整段截图中。本卷编辑需要以新题干排版，整段旧截图会重复题干，也无法作为一张独立图通过交付核对。真实物理题可保存四张原选项图，修改题干后的正式确认停在缺独立插图。

教师完成结构核对时，系统从同一解析版本中寻找位于原题裁片内、归属明确的图像或图表区域，按页码和坐标裁出独立 PNG。对于跨区、近邻图注、正文重叠、归属不明和低置信度区域，保留原件和待核状态。规则依据版面、文字行归属、原题锚点、像素尺寸及注册版本，无具体书名、题号或固定页码规则。

本卷编辑可以在新题干和选项之间使用独立图，选项图继续随原字母排列。原题模式继续使用整段截图和原选项图，避免重复显示同一装置图。尚不能单独裁出的图仍触发现有交付检查。旧网页补答或答案册记录冻结其原题证据，重新核对沿用当时保存的题图证明。

## 修改范围

- `material-structure-illustrations.ts` 确定可证明的裁片并校验区域、页摘要、栅格摘要、尺寸、图片哈希和锚点。
- `material-structure-repository.ts`、`material-question-archive.ts`、`material-structure-runtime.ts` 与 `db.ts` 在原结构归档事务内接入裁切、资源读回和核对记录。原题版本、整段截图、原始 OCR 和数据库表结构沿用既有契约。
- `question-document.ts` 提供独立题图契约。`PaperQuestionImages.tsx` 与 `paper-instance-content.ts` 分别接入原题显示及本卷编辑，旧版图例继续沿用原顺序。
- `structure-illustration-boundaries.mjs` 和 `paper-instance-graphic-electron.mjs` 覆盖规则、来源兼容与跨页自然样本。`paper-instance-ui-driver.mjs` 使用预览页的实际返回入口判断预览就绪。

## 数据和回滚

每道题最多 8 张可证明的独立图，每个来源页按需本地读取。额外成本是裁片存储、校验和渲染，图片按内容寻址复用。旧链路无独立裁片写入，本轮未测整个资料库的吞吐或容量。没有新增第三方依赖，也没有 SQLite 表迁移。回滚应用前备份题库，新建的题图证明和编辑后快照使用支持该契约的构建恢复或交付，已生成的 Word 文件可独立使用。

本轮验收证明一份真实正式题目的编辑、组卷确认和 Word 文件链路。多套完整正式卷、自然题留出质量、独立检索指标、约 10 GB 持续运行和跨机迁移继续按 Goal 台账验收。

已登记的上海数学题册只读统计显示，20 个本地结构组均带 `ambiguous_columns`，其中 8 组只有这一项疑点。页级疑点目前会传给该页所有题组，答案册的真实模型回执和正式配对也仍待执行。接续工作先核对题组跨度、原有区域证据和真实双栏反例，再决定能否把局部栏序疑点限制在受影响的题目。
