# 联网选择题答析冲突拦截

旧写回只对照网页的答案字段和原印答案。已有答案为 C、网页答案也标 C 时，解析即使明确写“故选 D”，旧写回仍会修改题库。新增的 SQLite 回归先复现了这次错误写入。

现在从已核对的选项比较网页答案和肯定性的选择结论。识别单选、多选、全角字母和分开的详解段。条件讨论、错误解法举例、排除项和普通提及按来源上下文处理。明确选中未列出的选项，或字母后的文字与对应原选项不同，也会停在候选。教师可在题本查看冲突原因和网页原文。

独立代码审查复现了结论后附解释文字、错误解法引用和跨分号假设三个边界。最终构建对这三类增加了回归，桌面反例使用带后续说明的冲突结论。

## 代码、性能及兼容

- `question-web-solution.ts` 在精确匹配后比较选项字母与显式结论。`question-web-answer-repository.ts` 在写回事务中选择候选状态。
- `question-web-answer-tools.ts` 和 `QuestionWebAnswerEvidence.tsx` 使用原工具和题本入口显示原因。专项扩充 SQLite 边界和桌面路径。
- 早期候选复读保存的实际 DOM 回执，9 轮各 100 次判定，中位 0.026 毫秒一份。上一轮的内存记录约为 0.031 毫秒，两值用于量级对照，浏览器与写库时间另计。
- SQLite 及 IPC 沿用原格式。回滚可恢复之前的匹配代码并保留已存候选、原答案及题目版本。历史题本写入与本次新增候选可继续读取。
