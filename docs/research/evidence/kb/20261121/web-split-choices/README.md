# 网页补解析核对完整选项

## 根因与修复

完整转写会分别保存题干和选项。旧网页匹配只用题干字段作字面比较，随后还要求选项字符串包含在题干字段内。选择题如果把完整网页原文引用进来，会被判成题面不一致。

新匹配在题干之后验证全部有序文字选项，并要求网页题目区只有对应题面、一个明确答案及有界的解析区。支持全角选项分隔符以及常见的「分析」「详解」连续分段。原资料的选择项字母可与网页中「字母加同一选项原文」核对。已有答案角色、原页坐标和教师确认由原事务保留，自动补写只填缺失角色。

修改 `question-web-solution.ts`、`question-web-answer-repository.ts` 及 `question-web-answer-tools.ts`。用原有 `question-web-document-boundaries.mjs` 和 `kb-reviewed-answer-journey.mjs` 覆盖合成边界和真实桌面流程。回滚可恢复旧匹配代码，现有数据库格式、原页和可审计的网页证据沿用原协议。

## 前后对比

真实 2022 年上海中考数学 PDF 第 6 题先完成教师转写，题干与四项分开保存。旧门槛拒绝包含完整选项的引用。新版内置浏览器在隔离环境访问受控网页，Readability 实际产生原始文字回执。小智从当前题库读取缺解析版本，经测试会话确认范围后，只写入网页摘录的解析。原印答案 C 及第 7 页坐标保持一致，普通题库检索找到同一条记录，冷启仍可读取来源和解析。受控模型和受控网页用于验证流程，付费调用数 0。

保存的实际 DOM 回执做 9 轮各 100 次内存复读，旧入口约 0.001 毫秒即拒绝，新完整核验中位约 0.031 毫秒。仅测题面判定与答案一致性，浏览器、队列、写库耗时另计。
