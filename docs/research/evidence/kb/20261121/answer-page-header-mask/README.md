# 独立答案册页眉的图文同步脱敏

## 根因

PDF 本地解析保留原生定位文本和 OCR 转录。旧答案册处理将两种转录与原页图片一起准备好，只要清洗器识别到联系方式就拒绝整页。这个拒绝保护了原图，但也让正文完整且页眉容易定位的答案页无法使用两遍转录与后续配答。

## 修改

- `material-ai-answer-page-mask.ts` 使用已发布的本地版面和原始 OCR 回执定位高置信度页眉。只有与版面 OCR 完全对应、存在匹配的页眉区域、且外扩后的矩形不压住其他行或区域时，才生成派生副本。
- 各份登记文字按原有顺序独立匹配精确页眉，空白只用于定位。保留范围之外的原有字符、换行和顺序。遮盖前后尺寸一致，像素只在冻结的矩形内变白。派生文字再经过同一隐私清洗器检查。
- `material-ai-repository.ts` 把结构代、结构摘要、原图摘要、遮盖坐标、派生文字和派生图像摘要冻结在新批次。每次执行都从相同来源重算派生输入。两遍模型调用及恢复续跑都必须使用同一派生图文，不能回退到原图或附带其他裁图。普通资料和旧批次仍按现有门槛检查。若答案页已有隐私标记，只有每条页内标记都能由同一处已定位的遮盖解释时才可使用派生副本。原标记保留，正文隐私和无法定页的标记拦截派发。
- `material-ai-page-evidence.ts` 校验回执关联的派生图，材料页独立展示模型核对副本、原件和本地转录。批次与文件夹授权说明提示遮盖行为，仍需教师本批勾选资料和云端授权。
- 专项脚本检查单页派生、授权、实际模型请求结构、冷读回及拒绝路径。测试样本始终保留原件。

## 回滚和适用范围

新策略只用于明确绑定角色的 PDF 答案册，从原有 OCR PDF 回执和可认证本地结构生成副本。不修改数据库表、原件、源 OCR 和原有回执。可设置 `OMNI_EDU_AI_ANSWER_PAGE_MASK=0` 停止创建新遮盖输入，已冻结的历史输入仍可读取和核对。若需要回滚代码，先暂停使用新投影的批次，保留其审计回执。没有独立发布或安装包变更。

手动多页批次如果混入无法解释的已标记页，当前仍沿旧入口拒绝创建。目录后台继续以独立页为执行单元。该策略暂不应用于题册和非 PDF 资料。

本轮处理隐私阻断。真实 DeepSeek 的答案准确率和正式配答仍按原合同验收，问题册的结构候选、独立检索、正式三套卷、约 10 GB 混合运行和换机迁移继续验收。
