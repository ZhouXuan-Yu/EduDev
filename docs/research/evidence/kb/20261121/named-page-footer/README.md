# 有版面证据的页码行退出题干和索引

## 根因与修改

同一条页码 OCR 行包含短标题、当前页码和总页数。版面模型把标题分为页脚区，把页码分为页码区。旧规则只识别裸页码。前三页只找到页码区作为主区域，第四页的任何单区覆盖率都低于 60%。恢复器将这些行归为正文，并附到每页的最后一题。

v13 继续按原流程恢复段落。短标题和完整页计数须与当前页号、总页数一致，同时得到同一基线上的相邻高置信页脚区与页码区支持。联合覆盖须达到 85%。明确的正文区域、错误页码、错行和重叠大块继续走原有分类。匹配只用于角色判定，原 OCR 字符、原图和归属坐标仍按原件保存。普通裸页码和已有页脚走既有路径。

- `apps/desktop/src/main/assets/material-document-structure.ts` 用原版面联合证据恢复页脚角色。
- `apps/desktop/src/shared/material-document-structure.ts` 发布 v13，保留旧解析世代的读取。
- `material-structure-identity.ts`、`material-structure-repository.ts` 在旧同源题校验中识别已证明的页脚差异。旧题原记录、确认状态和原件保持。正文变化或页脚证据不足不复用旧题。去掉页脚后仍须有原始正文行。
- `document-structure-boundaries.mjs`、`document-structure-repository.mjs` 和 `kb-column-structure-readback.mjs` 检查规则、历史兼容和实际桌面重建。

## 真实资料前后对照

已登记的上海数学 PDF 有 4 条页码行，版面联合覆盖分别约为 97.23%、97.23%、96.96% 和 88.59%。旧版四条均作为正文，分别进入第 10、17、19、21 题。新世代四条均以页脚角色保留，退出题干、子问和新正文索引。4 页原始文本、176 条 OCR 行、125 段和 20 个题组均可读回，其他 16 道题的结构内容保持一致。现有页源核验仍隔离全部 20 个题组，新增规则草稿和正式题均为 0。

教师从材料页重建并对照原图，旧世代和资源哈希、确认题记录、答案册关系、调用账目全部核对一致。缓存重建约 2.2 秒，实际外发 0 次。自然双栏反例保留原栏界和已有待核状态。带前置封面导致印刷页号与文件页号不同的旧版页脚继续走原识别路径。

92 个冻结 OCR 页的新旧内存对照只在上述 4 页发现段落差异。9 次交替运行的页结构恢复中位用时为旧版 15.14 毫秒、新版 15.40 毫秒，范围为整批 92 页，不含 OCR、数据库或首次导入。

## 验证与回滚

专项覆盖联合区、错误页数、间距、重叠、低置信度、正文冲突、旧教师题复用与正文实际改变。SQLite 表结构未变化。回滚前备份，旧世代可用支持其引擎的版本读取，新版派生世代可重建。页源正文、公式和题号核验继续按原合同执行。

下一处页源核验已定位到具体安全边界。试卷说明与正文共用一个印刷题号时，原生文字框可按坐标隔离，但真实同一题内的集合符号还有私用区字符与 OCR 普通字符差异。将放行范围限定在能证明版面归属和数学内容等价的题目，继续核对原图而保留现有独立 PDF 页源闸门。独立答案册、检索、组卷、约 10 GB 和异机迁移仍待整体验收。
