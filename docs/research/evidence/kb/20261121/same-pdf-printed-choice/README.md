# 同册 PDF 印刷选择题答案

## 根因与产品结果

同册后附的答案常连排印刷。通用解析把一整行解释成开头题号对应的新题，缺少在原题与答案页之间建立证据的步骤。拟配答链路此前要求独立答案册配对。

结构 v15 在资料导入时识别独立的参考答案标题和题型章节。PDF 原生行与本地 OCR 必须在同一区域逐行一致，合法题号须连续。每个字母只从能精确定位的题号及字母区读取。系统核对原试题唯一章节、完整题号顺序和实际选项，才在发布事务中写入已有的原印答案角色、资料版本、答案页及坐标。识别不清的格子保持空缺。题本现有「查看全部原图」入口可打开对应的答案原图。

题面改写时，原样保留独立印刷答案会被拒绝，教师可核对并改答或清空。拆分排版可保留字面一致的题干和选项。自动题面图片沿用原导出路径，题本答案原图独立读取。选择题答案为原件提供的内容，缺失解析仍待补，正式入库与组卷资格沿用教师核验。

## 文件与兼容

- `material-pdf-printed-answers.ts` 与 `word-booklet.ts` 共用印刷编号语法，分别验证 PDF 位置和 Word 原段落。
- `material-document-structure.ts`、`material-structure-repository.ts` 和 `material-question-archive.ts` 区分已确认答案区域，在后台发布中保存和验证答案角色。
- `question-document.ts`、`original-question-repository.ts` 与 `QuestionArchiveEditor.tsx` 拦截旧答案跨题面沿用，复用题本原图与题库编辑入口。
- `pdf-printed-answers-boundaries.mjs` 与 `kb-native-section-readback.mjs` 检查正反例、原页、实际编辑、重建及重启。

SQLite 与接口沿用现行格式，v14 及先前支持的解析世代仍可读。老师可用资料详情的「重建结构」生成 v15 派生结果。需要回滚时，先备份本机目录与 SQLite，保留旧教师记录和原件，再从使用该解析世代的应用重建派生资料。

## 真实样本对比

2022 年上海中考数学 PDF 同一原件连续 8 页。v14 归档 3 条选择题草稿，0 条有答案。v15 归档 3 条，原第 4–6 题分别读到 D、A、C，36 个其他题组仍待核。第 7 页印刷键保留答案角色。无印刷解析的第 6 题继续标记解析缺失。运行没有对外提交模型请求。

冻结原件上 9 组各 50 次输入，局部答案校验与范围匹配中位数 0.350 毫秒。开发隔离环境首次导入 v14 为 138.0 秒，v15 早期候选为 115.3 秒，两次独立运行，无吞吐提升结论。

## 限制

暂缓无原生文字互证、缺少明确答案标题或题型章节、重复试卷范围、边界不明和无法单独定位的印刷格子。本轮自动绑定横排印刷选择题，不覆盖填空、综合题、手写批注和跨页排印的答案。仍需完成自然样本的缺答与解析闭环、正式检索、正式三套卷、约 10 GB 规模和干净 Windows 换机。
