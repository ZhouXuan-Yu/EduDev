# 独立答案册的续页速查表

有些独立答案册把速查表单独排到下一页，页面只印表标题、题号行和答案行。旧策略要求同一页有卷名，因此即使题号和列值都可读，也无法定位到题本。

新答案页保存 `answer-entry-continued-table.v5`。能完整读取的三行表先保留候选，卷名由本地配对索引验证。两遍全文、题号与字母必须一致。沿相同原件、版本、解析代和配对版本逐页核对，每个页缝题号必须恰好连续，最终找到原印卷名，最多向前核对 32 页。文本不足、缺页、跳号、额外内容、短表、疑似不同试卷和来源变更继续待核。借用标题会保存每页的身份和摘要。前置证据缺失会阻止写回，已存条目的来源读回也会重新校验。答案表只填入原有空缺或可替换的答案字段，原有解析继续按其各自来源读取。

| 文件 | 改动 |
| --- | --- |
| `shared/material-ai-page.ts`、`shared/material-book-answer.ts` | 冻结新单元策略以及待确认的表续页状态 |
| `main/assets/material-ai-book-instruction.ts`、`material-ai-repository.ts` | 保留原印三行和两遍原文，使用现有派发流程 |
| `main/assets/material-book-answer-content.ts` | 恢复无卷名页的候选和原文范围 |
| `main/assets/material-book-question-section.ts` | 对紧邻的来源、题号与章节作完整核验 |
| `main/assets/material-book-answer-repository.ts` | 按保存的策略验证回写及冷读 |
| `scripts/education/kb-answer-section-boundaries.mjs`、`kb-ai-page-boundaries.mjs`、`kb-book-reference-journey.mjs` | 覆盖迟到前页、连续多页、来源失效及桌面目录流程 |

## 修改前后

同一独立答案表在前一页有原印卷名和第 1 题，下一页只有表头、第 2～3 题和对应字母。旧规则产生 0 条该页答案，新规则产生 2 条带原页偏移的候选。通过前页证明后，题本能从第 2 页取相应答案。9 轮各 1,000 次相同输入的本地投影，单页中位用时从 0.0091 毫秒到 0.0132 毫秒，未计入 OCR、模型和数据库。

另对保存的真实上海高考数学独立答案册 9 页做只读回放。两版输出完全相同，11 个候选仍按原证据待核。这份真实资料没有符合条件的三行续页表，无法用于证明自然续页的自动写回。

## 兼容、回滚与继续验收

SQLite 及已有回执格式维持兼容。设 `OMNI_EDU_BOOK_CONTINUED_KEYS=0` 可停止为新单元选择 v5，已使用 v5 的历史仍由同一读回代码校验。混合正文与表格、从页脚或多栏截断的速查表、真正分裂在两页的行列及缺少连续编号的材料仍待核。毕业考试的大题标题归一、真实自然题质量、检索指标、三套正式组卷、约 10 GB 与异机迁移继续按 KB-A01～A10 验收。
