# 结构原题的教师转写与补答检索

## 根因

题本原先为结构导入题显示“补全题面”，但保存只在会话原题审批台账中查题。批量导入题的原件和教师核对记录都在资料结构台账，查询因此失败。结构题维持旧版原图加文字摘要，正式小智补答检索和向量语料要求完整投影，无法提供已核对题目的完整上下文。现有网页补答也只接受带 AI 页档案的完整原题。

集成后另一个真实断点出现在浏览器执行记录。浏览器导航与提取已授权页面 DOM 均被标记为外部操作，导航记录未得到持久效果复核时，DOM 提取被按同目标重复出站操作挡下。

## 修改

- 复用教学工作台的题面校对表单、版本化 preload 调用和教师权限，为结构原题追加本地转写记录。现有题目必须先经教师核对，保存核对各项转写、原始资料版本、结构回执及已存裁图。已有图形、表格、公式、选项、小问的结构信息约束教师声明的范围。
- SQLite 事务将版本化转写回执与原题完整文档一起提交。同一请求重复提交检查一致性，正文编辑撤销旧的完整转写资格。既有原件、结构证据和历史 v1 题目继续读取，教师可按需补全，未批量重写。
- 补答检索依旧只暴露已核对、具备完整投影且确实缺角色的题目。向量语料校验结构和转写回执，实际读取重新校验原件版本与裁图。答案写回使用原有站点与本轮授权、Readability 回执、同题完整文字和逐角色证据，原图与已有答案保留。图义或表格依赖的网页内容仍只保留候选。
- 只将参数合法的浏览器 DOM 提取登记为本地缓存读取。导航和网页操作沿用原网络授权、任务范围、防止重复执行和浏览器会话隔离。对已确认的图形选项，原有富格式试卷编译保留逐项原图，避免升级完整文档后漏掉选项图。
- 网页补答后，教师仍可撤销题面核对并保留原网页证据，重新进入待核。没有改动模型配置或第三方依赖。

## 修改前后与性能

两个不同教辅来源原本无法沿旧审批入口保存完整题面。本版实际用题本界面分别完成教师转写，并由小智在正式补答检索中实读，返回缺答角色与题面核对来源。旧版本拒绝读取，图形题缺图义时拒绝完成转写。

实际转写回执索引按题目 ID 和投影哈希精确命中。两条真实回执预热 50 次、测量 100 次，SQLite 查找、JSON 解析和 SHA-256 检查合计 P50 0.026 毫秒、P95 0.037 毫秒。此测量不含 PDF 哈希、检索排序、OCR 或模型耗时。入索引校验避免每个候选重扫整份原件，实际读取仍按原件校验。依赖审计存量 29 项，high 8、critical 0。

## 后续与回退

已核对结构题与独立答案册的直接配对仍未覆盖。现有答案册规则依赖 AI 页来源和该页区段证据，后续接通结构题需要真实题册和答案册，以及错册、同题号异章节、原件改动反例。KB-A01～A10 的正式检索留出、约 10 GB 导入、真实模型、组卷和换机整体验收仍开放。

回退时保留原件、原教师题面及转写回执。已生成完整结构文档和结构网页证据需要可识别本轮协议的版本读取，优先协调兼容修复。旧程序读取前应先备份当前数据，保持转写和网页证据可恢复。
