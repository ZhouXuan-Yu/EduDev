# 独立题图的标注间距复核

现有自然测试库有 23 份保存的裁图边缘通过但题目仍待核。逐项检查原图和历史响应，在一份压力选择题中发现两份图标签转录完全一致，题文和裁剪归属通过，图示说明仅在已知标注词前有横向空白。逐字比较把这处排版差异当成图义不一致。另有多份独立图确实在两份转录中同时漏掉电路标注，已有防漏守卫继续保留。

新 `figure-label-spacing.v1` 在独立图的两份原始字面转录逐字一致、来源图和 OCR 摘要匹配、两份说明都以完整字面转录作后缀时，仅比较说明中汉字与完整已知标注之间的横向空白。字面图注、变量内部空白、数字、单位、符号、图义、题文和选项的比较各沿原规则。只处理恰有一个独立图的题。未知版本、缺失或非独立证据继续走原规则。新任务冻结策略，原“本地来源核对”可在符合前提的旧任务中保存可重算审计。共用原 20 条候选上限、事务和教师内容保护。

真实自然题的本地核对从整页待核引用变为完整题文档，有一张正文裁图和一张独立题图。三项真实疑点仍保存，即缺少年级、答案冲突、后页边界未确认。资料页实际触发了本地动作，冷启动后在题本打开与历史摘要相同的两张 PNG。原 PDF、原裁图、原单元输入与回执、其余题目和付费计数通过核对。新增调用 0。对其他图示的人工语义一致性与全部自然版式仍需要真实留出验收。

副本在同一批次的真实动作测得 31ms。原规则只留下待核引用，本轮可在本地完成证据核对，原件无需重读上传。没有整库吞吐或大规模耗时结论。

首次构建因递归函数缺返回类型失败，显式收窄后通过。最初两轮 UI 的资料动作成功，题本用自然段前缀查询超时，最终改用该题唯一的公式短语并开启“显示原始候选”。保存失败日志与已写入前快照。现有题本关键词扩展会让常见词进入候选，短前缀的排名需要在后续检索阶段单独复现和修复。

无新依赖。npm audit 报告本机依赖树 29 项既有告警，其中 8 项 high，0 critical。回滚使用原来源版式开关停止新生成和写入，继续保留新老审计读器。实际样本和预写入数据库副本留在本机。完整 Goal 与 KB-A01～A10 继续原范围。
