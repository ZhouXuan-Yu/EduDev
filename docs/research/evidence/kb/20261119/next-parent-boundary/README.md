# 下一页局部争议与前页末题分界

## 根因与修复

旧 `followingPageStatus` 只处理状态为 complete 的下一页。真实资料库有两份 PDF，第 2 页的原生文字与 OCR 在后段不同，导致整页进入 needs_review。第 2 页开头的下一道题号及题干两套读数一致，前 1 页已有完整文档的末题仍被标为 incomplete_question。另一份真实 PDF 的第 2 页确实以续题内容开头。

新逻辑只在同资源版本、同解析代次、同总页数的下一页因 text_conflict 待核且两套文本都从连续下一父题开始时比对页首。比较只使用现有文字排版签名、首行完整可见文字和明确题号。只识别实际页号和总页数吻合的页码行。形如“2 / 7”的裸分数还须在前页的可信页首或页尾找到对应格式。图注、标题、续题句、下一页隐私标记、文字差异和跳号继续维持保守结果。

新任务采用当前页已有裁图的边界证据。历史题可经资料页原“复核来源版式”入口修复。原题文档和教师状态保持，只移除重新推导出的页尾误报，下一页资源版本、页码和源摘要进入 `material_ai_next_parent_rechecks`。表增量创建。历史版式核对单独保存，原入口候选仍共用二十条上限。题本冷读会重新验证相邻页，后续源不再支持当前证据时拒绝未经认定的读取。

## 范围与回退

本轮只证明可独立确认的页尾新题边界。续页组装、跨页图表、不同出版社的排版、留出真实资料质量、约 10GB 和安装迁移仍继续原目标。遇到不能确定的页首时保留原争议。

设置 `OMNI_EDU_AI_NEXT_PARENT_BOUNDARY=0` 并重启可停止新发布或本地复核使用这个规则。已保存档案的读取仍验证当前边界，既有 OCR、影像和教师结果可保留。详细文件清单见同目录 MANIFEST.json。
