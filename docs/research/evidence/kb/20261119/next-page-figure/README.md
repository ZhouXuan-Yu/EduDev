# 上一页末题的独立续页图

## 根因

版面识别正确得到下一页上方的图和第一道新题，但装配器跳过图片段落，遇到新父题就结算上一题。只有题文的页面参与题图归属，纯图续页被遗漏。题库裁图还有同一前提，未找到题文段落就不会生成该页的来源图。两处一起导致教师看到“题图未完整定位”，无法通过原流程核对入题本。

## 修改

- 结构 v4 在两页同栏、题号连续、前题位于页底、新题是下一页第一段题文时检查独立页首图。已有图、多个页首资产、图形选项、断号、分栏冲突或图跨入下一题范围时保持原归属和待核状态。
- 印刷题干只引用一个图号，且实际图注确切一致、位置紧邻、无下一题同号引用时，图进入结构候选，随后仍经过现有的 PDF 来源准入。没有明确图号时，完整 A–D 文本选项及下一题自有配图只能支持待核关联，教师核对前不自动入库。
- 沿用现有原页 IPC 预览和教师校正。校正中可打开每个来源页并保留输入。题库裁图按归属坐标从已校验的原页取图，包含只有图片的来源页，同时裁开下一题内容。原始 OCR、原件、版面及历史结构仍可追溯。
- 已发布的 v1–v3 结构继续读回，v2/v3 已冻结 AI 来源回执仍可鉴真。中断的老代从 v4 开始新一代。留存原件和教师已核对档案；需要回退时撤回代码，按需用兼容版本重建 v4 派生记录，无 SQLite 表变更或新依赖。

## 修改前后

同一四页真实物理资料，第 7 题在 v3 只有第 3 页并因缺图无法核对。v4 把第 4 页页首一张图作为待核，保留第 3 页完整 A–D，教师在桌面查看两页后保存，冷读能看到两个来源裁图和核对记录，文件 SHA-256 与题库回执一致。第 8 题的三张配图仍归第 8 题，第 6 题公式分歧仍待核。另一份真实上海物理试卷在翻页处有四张成组选项图，专项验证这四张图不会被吸入单张续页图路径。

对同一批 4 页和 7 页已保存版面做配对测试。50 次预热后各执行 100 次，11 页结构装配 P50 由 1.085 增至 1.155 毫秒，P95 由 1.910 增至 2.174 毫秒。OCR、渲染及数据库耗时另计。依赖审计 29 项存量问题，high 8、critical 0。
