## 教师完成的操作

- **原电脑更新**。在现有「设置」入口看当前版本、更新内容、兼容性和重启提示。安装新版前创建并校验可恢复的本地快照，等正在写入的任务结束或由教师明确中止。重启后继续原教学工作。
- **换到新电脑**。旧电脑在「设置 → 备份与恢复」生成并校验搬家副本。教师通过自己选择的介质搬走完整备份。新电脑安装兼容的小智，选中备份后先看核对结果和需重新绑定的项目，再确认使用新副本。原电脑和新电脑原有数据各自保留。
- **撤销**。换机后可切回新电脑原资料。升级回滚使用保留的旧程序与升级前数据快照，恢复选择前展示旧版本和快照时间，并保留新版中已产生的教学记录供后续取回。
- 首期按一次性迁移及同机更新验收。两台设备继续并行编辑后的同步或合并需要另行确认产品行为。

## 一致性的定义

| 分类 | 目标 |
| --- | --- |
| 业务资料 | 资料库层级、原件及页码定位、题目及答案、跨题源关联、组卷草稿和已交付试卷、学生档案、错题、学习记录、教师确认及修改史都可在新电脑按原入口查看。 |
| 小智对话 | 历史及其顺序、引用、文件版本、任务阶段和检查点、审批历史、已保存的报告和产物保持可追溯。正在运行的本地终端和进程结束于旧机，新机显示可恢复状态。教师从安全检查点明确继续。首开不会重发模型、写文件、提交审批或触发待运行工具。 |
| 熟悉的使用方式 | 可迁移的模型偏好和思考档次、工作台偏好、个人 Skill、已编辑模板与快捷设置保留。依赖相同可用时执行路径一致。窗口尺寸按新屏幕适配，默认应用按新系统关联。已有成果的预览、文件树定位和另存为指向新位置。 |
| 新机确认 | 模型和连接器密钥在目标系统重新输入或登录。外选资料路径、外部目录权限、MCP／工具能力及环境依赖在新机重新验证。审批历史保留，未执行的授权按既定权限合同重新判定。丢失或不可读项目标出名称、原因和修复入口。 |
| 索引和运行时 | SQLite 与原始文件随副本，派生索引和缩略图在目标机重建。展示重建进度、可使用的功能和待就绪项目；完成后用固定检索和引用核对结果。安装时按目标机查验随包与受管依赖。 |

相同版本、相同资料和相同配置下，验收比较的是教学任务、事实、校验结果和操作路径。模型的自然语言措辞、启动耗时以及系统应用列表受实际设备和服务状态影响，分别记录。

## 实施顺序

1. **扩充现有备份及恢复契约**。继续使用 SQLite 一致快照、受控原件和成果清单、文件摘要校验、准备副本与激活指针。为后续格式记录应用版本、数据库格式版本、可迁移配置、所需空间及遗漏。读入旧清单时保留已验证的兼容路径；缺失迁移信息时说明用哪一版本重新备份。点验当前备份对模型凭据、连接器凭据、个人 Skill、模板和偏好的覆盖，迁移包以显式允许的配置字段为准，避免直接复制整份系统配置。加密凭据的占位或清理不得改变源库。
2. **通过新机恢复预检与任务接续**。将可变盘符、用户名和数据根路径映射到新机，保留原历史证据。源盘不可访问时仍能校验已复制资料。包内无权限的路径明确要求重选。目标已有教师资料时先创建独立副本，再确认是否切换；出现空间不足、断开、损坏、版本较新、取消或启动失败时，保留可启动的原数据。
3. **交付可验证的更新路径**。先支持通过受信发行来源获取更新，由用户选择时机，校验签名、版本和候选摘要，并用已有备份链路准备升级快照。验证 N−1 → N，随后验证支持期内的跨版本路径。数据库迁移增量、可重复，遇错回退到兼容程序和升级前快照。应用程序安装路径与资料路径分开。自动下载和增量更新可在覆盖升级和回滚通过后评估。
4. **做独立 Windows 实测**。沿用 QG-09 原安装项并保留结果。使用两个隔离 Windows x64 环境或两个可验证独立系统快照，分别记录 Windows 用户、盘符、安装包哈希和实际运行路径。迁移矩阵按下表执行。受控 source smoke、同机开发版恢复、真实安装升级和异机恢复各自保留结果。

## 2026-11-21 基线

- 源码基线 4b4ebe4。现有产品具备本地备份、SHA-256 校验、恢复到新目录、确认切换和回退。默认产物与已登记外选成果有独立复制路径。现有备份 v1 清单记录格式和文件完整性，缺少用于升级预检的明确来源应用版本和数据库兼容范围。
- 本轮在 Windows 使用真实临时文件与 SQLite 执行 backup-restore-smoke.mjs 8/8、external-output-backup-smoke.mjs 7/7。覆盖文件字节、路径迁移、回退、盘满、篡改、符号链接和外部成果变化。未执行异机、跨版本安装或真实教师资料验收。
- 正式软件入口继续沿用 [Windows 安装合同](WINDOWS_INSTALLER_CONTRACT_20261023.md)。切换恢复副本机制继续沿用 [架构入口](../architecture/CURRENT.md)。现有安装候选尚待 QG-09。
