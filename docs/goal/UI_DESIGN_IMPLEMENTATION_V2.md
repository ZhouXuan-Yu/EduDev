本任务书从属于 [Master Goal](XIAOZHI_CODEX_GOAL.md)、根 AGENTS/CLAUDE 与原有领域合同，不替换它们的产品、数据、阶段和完成定义。U编号仅是本UI专项内部顺序；若前置领域能力未稳定，不用UI实现绕过。现有 WORK_PROGRESS 与领域任务由各自负责AI维护，本设计稿不自动登记其AT完成。

**冻结范围**：现有输入框、底部工具栏及其弹层整体保留，不改配置/尺寸/排列/行为来迎合原型。使用实际 `OfficeComposer`，原型 composer.js 不能复制替换。只保留浅色。不得增加 UI 库、修改 vendor、全局 important 或全局控件选择器覆盖。

## U1 · 真实过程与最终正文

- **UI-CHAT-01** 以同一 sessionId/runId/turnId 的真实公开说明、工具开始/结果、最终正文与终态映射展示。状态“请求已接受/等待服务”不冒充思考步骤；无工具任务不造工具、无推理不补推理。无私有推理内容进入默认过程/正文/截图日志。
- **UI-CHAT-02** executing 时自然展开；**首次明确最终正文事件**到达时整段收起，正文继续逐字流式；之后可手动展开查看。中途公开说明不是最终正文，不触发折叠；失败/停止/审批不假装正常完成。接口无最终边界时先形成兼容适配方案，不能靠 timeout/关键词猜测。
- **UI-CHAT-03** 顶部唯一用时从首次公开执行活动到正文交接冻结。完整请求/生成用时如需显示，进入详情且标明口径；正文阶段不能继续累加“执行用时”。冷启以持久事件时间恢复。
- **UI-CHAT-04** 读文件/搜索/执行/写文件使用不同既有图标与文字，运行/成功/失败/取消可区分；查看详情不移动输入焦点，不另加输入框上方重复过程条。
- **UI-CHAT-05** 零工具、连续工具、工具失败后恢复、停止、待批准、正文中断、刷新/冷启、切会话至少各一条真实路径；只有对应 run 的事件可更新该回复。错误保留已生成正文与恢复提示。
- **UI-CHAT-06** 先检查同模型同上下文的实际 system/skill/任务要求对正文的影响，再独立评估提示词变更。允许教学流程/题目使用列表，普通解释用自然段；不从界面强行拆/合段，不宣称像 GPT 就必须隐藏列表。教师评审回答可读性。

出口：同任务原始事件元数据（不保存私有内容）与时间戳、界面顺序、折叠时刻、首正文时刻一一对应。不能用 HTML 5 秒演示代替真实验证。

## U4 · 智能组卷

**2026-11-01 最新已确认原型方向**：以 [组卷V3需求](../design/system/ideal/QUESTION_STUDIO.md) 为准。取消“几道题/练习/试卷”三个同质首页，找题与选题 ⇄ 整理与编辑 ⇄ 预览导出。后端来源策略保留，不等于需要三个UI模式入口。原型专项26项仅证明HTML交互，不能关闭下方生产验收。

1. U4-A：复用现有路由/题库查询/题篮，完整题目为主区，章节知识点与筛选组合；独立返回、继续选题及前进后退验收。
