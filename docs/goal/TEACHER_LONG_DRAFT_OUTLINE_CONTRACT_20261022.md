## 第一性判断

- 教学 Markdown 已有稳定标题结构，宿主可直接提取目录，不需要模型或后端解析。
- 目录只在至少两个标题时显示，默认折叠，避免短文件增加干扰。
- 点击目录项应跳到真实渲染标题，并给出可读定位反馈。
- 目录不得执行 HTML、读取脚本或发起网络请求。
- 该能力不改变文件字节、版本、审批、目录授权或模型上下文。

5. 原文件树自动让宽、标签、版本变化、错误恢复、权限与冷启边界继续通过。
6. build、renderer错误和最终构建SHA冻结后不漂移。
