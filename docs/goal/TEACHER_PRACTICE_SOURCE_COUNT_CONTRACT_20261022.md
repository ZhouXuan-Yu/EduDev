# 教师练习来源题数与逐题核对合同（2026-10-22）

## 状态

`LIMITED_ACCEPTED`。本轮只改善“错题少练”的已保存练习来源弹层，不新增练习生成、作答或成绩业务。

## 教师可见问题

现有1366×768暗色截图显示，“练习来源与核对”弹层一次只露出第一题；界面没有明确告诉老师总共有多少题，也没有清楚提示可以向下滚动。老师可能只核对第一题就关闭。

## 第一性判断

- 两题以上练习必须让教师一眼知道总题数。
- 每题标题必须包含当前位置与总数，例如“第2/2题”。
- 长列表滚动时，题数提示需要保持可见，但不能遮住当前题目标题。
- 来源弹层为只读核对，不应添加保存、编辑或提交动作。
- 该信息只来自现有已确认练习快照，不重新读取模型或改写来源。

## 修改边界

- 仅在现有`PracticeQuestionList`增加题数提示，并将题目标题改为`第 n/总数 题`。
- `pi-practice-count`使用`role=status`和吸顶样式；题目卡增加`scroll-margin-top`，避免被提示层覆盖。
- 不新增IPC、SQLite、依赖、权限、模型调用或持久状态。
- 题目顺序、来源链接、版本、关闭与只读行为保持不变。

## 验收

1. 两题练习显示“共2题，请逐题核对；题目较多时可向下滚动”。
2. 标题分别显示“第1/2题”“第2/2题”。
3. 1366×768暗色真实弹层滚动到第二题后，第二题标题位于吸顶提示下方且可见。
4. 弹层关闭按钮仍在视口内。
5. 使用复制后的已确认练习数据库，不修改源数据，不调用模型。
6. renderer组件、build和diff通过。
