# M10/M12 浏览器控制与操作可靠性

基线 5f283e7。以问小智中的实际网页、确认面板、任务回执和重启后的本地状态验收。范围覆盖浏览器宿主、主窗专用 IPC、受管技能、右栏与本机网站登录。SQLite 业务表沿用现有 schema。

1. 老师接管后工具不再读写网页。停止、页面切换、迟到确认均不能重新授权；交还后重新观察。
2. 右栏与独立窗切换保留同一网页。切走对话或打开遮挡页面时收起原生网页，不覆盖对话。独立窗可作为回退入口。
3. 登录由老师在独立的 HTTPS 站点配置内完成，临时浏览继续隔离。清除操作针对该站点；已放行的外部请求保留未知效果处理。
4. 根据当前控件、已观察结果及绑定的页面执行。目标不可操作、目标变化、结果未出现均返回明确失败。
5. 运行构建、组件、原生网页、对话端到端和整机回归。区分本地页面、公开网络、合成模型及真实教师验收。

## 从教师入口验收

1. 在问小智输入“打开教育部官网，核对一条通知的标题和来源链接”。网页在对话右侧打开，点击“独立窗口”再“放回对话”，页面、滚动位置与未提交输入保持。隔离网或站点加载失败应显示具体失败状态。
2. 在动态筛选请求待确认时点“我来操作”。网页留给老师操作；此前的同意不能补发旧点击。点“交还小智”，用最新快照继续核对。重名、缺少选项、目标已被替换时，应停止该动作。
3. 打开已知 HTTPS 站点，先点“我来操作”，再点“打开此站的本机登录”，在新配置内手工登录。应用重启后对同一来源再次选择本机登录；观察站点按其 Cookie 有效期恢复登录。点“清除此站登录”并确认，重启再检查。首次切入持久配置重新打开站点首页，先保存未提交草稿。默认临时浏览独立；本版只支持同来源站点，跨域 OAuth 和依赖其他域的资源仍需单独适配。
4. 在已有列表上触发一次延迟更新，使用新的结果文字核对成功，检查只发生一次点击。超时或外部效果未知时先读页面。刷新、重启及重复打开会话均不得重放提交。
5. 恢复路径：右栏布局异常时可使用独立窗。临时浏览可单独使用。旧版分开调用动作和 wait 的接口继续兼容。回退版本前保留业务数据及技能目录备份，旧程序未必能读取新版技能目录。

## 尚待针对目标网站验证

人工多因素登录、跨域单点登录、复杂 iframe、文件上传下载、Canvas 内目标及含持续动态区域的网页需要各自验收。预期文本回读证明页面显示了该文字，正式提交的外部状态仍需站点回执。端到端性能按真实模型、站点和教师等待分别计时。

## 运行证据

在 Windows Electron 43.8.3 上，用同一页面的同一个按钮交替执行两种策略，各 20 次。页面在点击 100 毫秒后更新列表，确认由夹具即时回答。分开点击与等待的中位数为 227 毫秒，第 95 百分位为 242 毫秒。合并操作分别为 141 和 155 毫秒。独立的 Pi 对话用本机确定性模型验证了浏览器调用从四次减到三次，重启后 SQLite 和会话结果均指向同一来源。以上计时仅覆盖热浏览器执行段。 同时跑桌面回归时，单次本机模型对话从运行建立到完成为 27.437 秒，首个浏览器工具调用出现在第 14.695 秒。该样本包含 Pi 启动、手册、任务计划与确认，不支持整段提速百分比。

34 项原生浏览器检查覆盖相同 HTML 节点替换、不可用选项、已有结果、接管期间迟到的确认、停止对话时保护老师的页面以及关闭应用时等待登录清除。四次独立启动验证临时浏览隔离、持久 Cookie 恢复、网站离线时清除以及冷启动读回。登录验证仅使用合成 Cookie。

教育证据操作手册升至 v4。原 v2 和 v3 手册按各自原文校验，升级保留停用状态。历史业务库回归使用旧提交的存储实现生成隔离教师数据，并在副本应用仓库 v1 绑定表定义。日常数据根保持独立。

试验中的页面事件等待在换页测试里两次导致 Electron 退出，已撤回。交付版使用有上限的短间隔检查，每次读取在同一渲染任务内返回。网站暂时不可用时，老师仍可在同来源的浏览器面板清除本机登录。接管由桌面端的受信任控件发起，清除由主窗确认。

最终隔离构建通过问小智对话端到端 9 项、正文提取 9 项、组件 261 项和整机 207 项。对话窗口在两种验收尺寸与原生网页大小一致。依赖审计返回 0 项已知通告。

### 右侧工作区

“问小智”可主动打开右栏，在一排标签中切换网页和对话文件。网页使用现有 Electron 宿主，每页有独立的导航历史和加载状态。独立窗保留同一批网页，并提供地址栏、前进后退、刷新、停止加载和切换标签。网页工具继续遵循 Pi 的准入与教师确认。

对话文件从已授权的工作目录和保存成果打开，预览由现有 typed IPC 校验会话、原件和版本。文件保存在本地工作区，网页标签沿用原公网访问边界。工作区可拖动调整宽度，文件与网页可以各自关闭。验收入口与版本记录在日常项目 `acceptance/browser-workspace-r3`。
