# 教师备课的内置浏览器专项验收

范围为 M10/M12。从“问小智”发送自然语言，通过 Pi、内置浏览器、教师确认和回答完成操作。基线为 23bd15f。使用公开教育部通知与虚构的八年级物理资源页，每轮创建独立数据根和 profile。

| 教师任务 | 对照和通过条件 |
|---|---|
| 核对课程通知 | 从输入框发送原文 URL。打开同一官网页面，逐项对照落款、网页发布日期和实施时间。答案附原文链接，浏览器回执可追溯到该页；记录实际跳转地址。 |
| 筛选八年级备课资源 | 教师批准一次，延迟列表更新。对照网页点击计数、实验名和本轮生成的资料编号。未更新的列表、猜测和重复点击均不通过。 |
| 临时决定不筛选 | 在同一确认入口拒绝。网页实际点击为零、列表仍是全部年级，回答说明终止且不提供筛选结果。 |
| 页面变更、冷启动 | 旧快照不能读到新页正文。历史回执可读，重启不重放点击。由原生与确定性 Electron 回归核验。 |

修复范围是网页工具只读参数、宿主快照核对、工具说明与专项测试。兼容旧的整页和区域读取，继续要求区域引用配套快照。无 SQLite 迁移。回退本轮提交即可恢复既有入口。模型选择工具、页面点击计数、教师本人是否验收分别记录。

## 教师亲自复核

1. 打开专项验收窗口，进入“问小智”。发送“我在备课，请用内置浏览器打开 https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html 。按原文分别列出通知落款、网页发布日期和课程实施时间，附来源”。点击来源，逐项核对名称与数值。该页出自教育部，通知落款为 2022 年 3 月 25 日，网站发布日期为 2022 年 4 月 21 日，执行时间为 2022 年秋季学期。网站改版或下线时保留原回执，标记来源待核。
2. 在自己选定的公开教学资源目录发起“筛选八年级，列出更新后前两项”。先看网页上的全部年级，在输入框上方拒绝该次筛选，核对列表和回答；新开对话重试并批准一次，逐项核对实际列表与回答。记录网址、列表顺序、重复点击和是否发生额外确认。线上目录由教师选择，自动用例使用隔离资源页。
3. 在两个同名入口的目录中要求打开指定课时。观察小智能否根据页面区分入口；仍有歧义时应请教师指明。等待列表更新时停止，或手动切换页面。检查原任务是否如实显示中断，关闭再启动后历史仍可读，页面没有再次提交。
4. 可选题解复核。选择包含图形或公式的公开课例，要求“请读题解并标出只能在原图核对的地方”。对照原页和本地截图；记录缺失、截断和教师修正。不得用模型补出的条件当成原文。

从候选工作树的 `apps/desktop` 运行。三个命令分别新建 profile、SQLite 和 Pi 会话。使用应用已有生产模型配置；每次输出各自的 report.json，记录模型、构建摘要、工具回执、网页实读和最终回答。筛选与拒绝两例仅在隔离浏览器的网页会话内提供合成页面，模型始终自行规划和调用工具。

```powershell
node scripts/xiaozhi-agent/pi-browser-teacher-live.mjs notice
node scripts/xiaozhi-agent/pi-browser-teacher-live.mjs filter
node scripts/xiaozhi-agent/pi-browser-teacher-live.mjs decline
```

## 2026-11-27 运行结果

基线官网场景停在等待确认。Pi 记录显示模型把当前 tabId 和 snapshotId 一起交给整页 extract，工具返回失败，模型改用另一工具，未在时限内提交结果。两个基线筛选任务都完成，导航与点击复用同一步骤曾被拒绝，模型需重新登记计划。

修订后生产工具支持“指定标签 + 当前快照”读取整页。导航与筛选各用独立计划步骤；继续逐次核对点击权限。原生回归覆盖旧接口、作用域、同标签快照过期和提取期间换页。构建主入口 SHA-256 为 `17d920a7d8240a33eb48c10ea7f48958cb1dcb7b94645dfb4dfa3e445e13cd46`。
