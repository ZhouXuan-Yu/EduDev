# 内置浏览器 DOM 操作与验收方案

真实模型后续复核覆盖教育部通知与动态筛选的同意和拒绝。见[教师复核与实测记录](BROWSER_TEACHER_ACCEPTANCE.md)

M10/M12，基线 ca2a514。教师从问小智发起网页任务，在同一张隔离网页上核对动态筛选结果和来源。既有 Pi、Electron 网页、Hana 快照、Readability、本地截图及教师确认承担现有职责。

## 执行顺序

1. 在相同 Electron 页面复现异步结果、页面重绘、重名目标和接管换页。记录旧工具能接受的参数和结果。
2. 使用现有受管技能入口交付浏览器操作方法。复用腾讯 BrowserSkill 的观察、动作、同步及未知效果处理思路，提供公告、筛选和题解三个示例。核对现存技能目录升级和停用设置。
3. 验证 Playwright 在隔离测试中识别实际 WebContentsView 的能力和连接范围。生产使用仅限宿主绑定的网页。新增只读语义查找，返回最新快照中的唯一引用，点击仍走原引用校验和逐次确认。增加绑定页面的可取消条件等待；旧参数保持兼容。
4. 用生产工具入口和真实 Electron 对照，执行构建、组件与整机冒烟，记录独立验收、实际窗口、提交及远端状态。

## 验收

| 场景 | 通过条件 |
|---|---|
| 现有/新工作区技能 | 可发现并读取浏览器手册，恢复后内容一致，旧技能与用户状态保留 |
| 动态筛选 | 页面重绘后按名称、角色找回唯一目标；批准一次，点击一次；读到延迟出现的目标文字和页面来源 |
| 同名、隐藏、过期 | 不猜测重名；隐藏项不能作为命中；旧快照不能执行动作 |
| 换页、停止、超时 | 等待过程中变更页面或停止立即失效；目标缺失给出明确结果；没有迟到动作或自动重提 |
| 教师拒绝、跨会话 | 拒绝无页面效果；另一个会话的标签不能作为目标 |
| 现有路径 | 原导航、正文提取、截图本地读回、任务准入、双尺寸页面与冷启动回归 |
| 教师验收 | 从问小智打开公开教育网站，定位公告，核对正文和日期，点来源复查；将模型、网络及人工验收分别记录 |

共享动作类型、工具 schema、Pi 工具描述、执行宿主、受管技能和浏览器专项测试同步修改。复用现有界面/授权接口。无数据库迁移。可回退本轮源码并使用旧版工具入口；检查旧版本对新增内置技能目录的兼容性后再进行应用版本回退。

## 选型依据

小智的教师和 Pi 需要共享同一个可见标签。保留 Electron WebContentsView，直接复用既有 Hana DOM 快照与 Mozilla Readability 正文提取。查找控件时使用当前标签的 Chromium 可访问性树计算角色和名称；动作仍由宿主用当前页面引用执行。Canvas、几何图和图片的语义需要视觉信息，教师可查看本地截图。此次未引入图像上云。

腾讯 BrowserSkill 的 DSH 插件使用已经登录的外部 Chrome/Edge。手册借鉴它的观察、动作、核对顺序，保留 Pi 的受管技能目录和小智的宿主权限。Playwright 用于桌面验收。Lightpanda 面向无头自动化，不能直接承载教师观察和接管的可见页面。本次没有新增生产依赖。[BrowserSkill 插件](https://github.com/Tencent/BrowserSkill/tree/main/packages/dsh-plugin-browserskill) · [Playwright MCP](https://github.com/microsoft/playwright-mcp) · [Lightpanda](https://github.com/lightpanda-io/browser)

## 教师复核

1. 在“问小智”输入“在内置浏览器打开教育部官网，找出一条当前可见的通知，核对标题、发布日期和来源链接”。需要网络和已配置的模型。按来源打开原页，核对标题、日期和 URL 相符。
2. 在带筛选控件的公开教育资源页要求“筛选一个年级，等列表更新后读前两项”。对照浏览器可见列表；同名且不能区分的控件应提示核对。对有副作用的操作点拒绝时页面不能产生该效果。
3. 再发起筛选，在确认弹窗中同意，核对只触发一次。动态页面等待期间停止，或接管浏览器切换页面，原步骤不能报告成功。重启后历史可读，浏览器不自动重做操作。

## 回归入口

工作目录为 `apps/desktop`。构建用 `npm run build`。渲染组件用 `npm run test:renderer-components`。整机脚本为 `node scripts/electron-smoke.mjs`。浏览器专项依次为 `node scripts/xiaozhi-agent/pi-browser-native-smoke.mjs`、`node scripts/xiaozhi-agent/pi-browser-dom-ui.mjs`、`node scripts/xiaozhi-agent/pi-browser-extract-boundaries.mjs`、`node --experimental-transform-types scripts/xiaozhi-agent/pi-browser-guide-upgrade.mjs`。原生测试含公开 HTTPS，界面脚本在独立数据目录使用本地确定性模型响应。
