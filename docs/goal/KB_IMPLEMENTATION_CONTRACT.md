## S5-B3 — 中文有限交叉编码器重排（M04/M10/M12）

目标：资料/同题库/Pi在现FTS+BGE+RRF的有限候选上进一步比较题意，不把余弦或模型logit当正确率。先实测MIT BGE-reranker-base q8（Xenova固定镜像，279301077字节）与Apache-2.0 BGE-reranker-v2-m3 q8（ONNX-community固定镜像，570727094字节），记录CPU冷/热延迟、内存与独立中文分级标注探针质量，再按本产品CPU/包体选择实际随包模型。两项为评估候选，不承诺全部预装。复用已锁ORT/tokenizers/Numpy/PyInstaller构建环境，无PyTorch/服务/运行时任意下载；许可证和全部字节/源SHA锁定后构建独立冻结EXE，旧embedding包不变。

重排只重排有界已召回对象，保留未评分尾部并报告覆盖，不用阈值误删可能相关题。候选文本按完整短题/语义命中窗与必要首尾有界准备，溢出明确非完整上下文；两阶段之后再次复读SQLite及来源/隐私/版本，不允许等待期间变私密的旧内容返回。新私有版本化重排协议、懒启动/空闲退出/并发有界/超时与可取消子进程；失败保留原RRF结果并显示降级，原事实/索引世代不变。typed现有检索输出与前端提示、Pi上下文同步。

实测开发pilot20例选轻量base：原embedding NDCG@3约0.855，纯cross约0.874（9提升/5退化），m3约0.883但约2.6倍耗时；因此不让cross独断排序，以原召回与cross等权RRF保留信号，开发pilot约0.876、退化2例。另冻结新16例独立验证集，不将开发集继续称holdout。新增retrieval_source_revisions派生来源时钟，逐返回对象及其来源做最后一次SQL版本栅栏，兼容历史seq0，避免全库maximum变化误清无关结果。来源正在变化时只剔除受影响结果并明确partial；这不是新的业务数据真源。

必要验证为独立合成中文分级标注的before/after质量pilot、真实冻结模型排序/边界、源变化/失败/限额/缓存守卫、实际Electron资料与题本/Pi接线以及build/renderer和发行资产闭包。不将合成pilot称自然教师holdout，不以少候选热缓存值声称百万级P95≤2秒；冷启动、背景导入与质量退化均分别报告。原本地/逐批云授权AI整理规则不变；此模型不是视觉AI自动识题。完整目标、旧代GC、图文/DOCX、40GB与最终main合并继续。

预算：每个 DOCX 输入沿用50MiB上限；条目5000、XML总量24MiB/单件8MiB、实际展开总量128MiB、最多512张内嵌图/单图8MiB/图总量64MiB、100000 XML节点/深度96、20000结构块。每个单元受控结果与超时/取消，单个坏文件不阻塞文件夹后续任务。以上是设计拒绝边界，不是已测极限。

验证：真实合成 DOCX（自动编号、分式/根式/上下标、跨表图片、坏关系/外链、空图、DTD/解压超限）→文件夹导入→SQLite/图像SHA readback→资料页/来源查看→冷重启；独立AI批判后修复。旧测试资料可显式重整，已有题目来源和正式教师事实不静默重写；保留旧 Office 通道供其他格式使用。

本轮对已锁定 MIT anydoc 0.1.2 做了原生结构探针（`node scripts/education/kb-word-structure-probe.cjs`）：合成 DOCX 包含正文、OMML 分数、内嵌 PNG 和答案表。当前 Markdown 通道只剩图片替代文字；直接 toDocument 能保留同 SHA 的 68 字节 PNG、assetId 与 originPart，但 OMML 的 1/3 在 Markdown 和 AST 中均缺失。这是实际库能力边界，不将未进入表示的公式交给 AI 猜。

下一切片沿用现有 anydoc，并补有界 OOXML 结构读取，不新增第二套 Agent 或大型服务。先完成版本化资料结构契约（段落/表格/公式/图像、part 与块位置、来源 hash、处理版本和缺失警告），再贯通 Worker、SQLite/受管图像文件、typed preload、资料查看/定位、OCR/AI 输入与题库。Word 不虚构页码；teacher-confirmed question-document.v2 不冒充 AI 定稿来源。外链图片不自动抓取，嵌入对象不执行；不支持的公式/图像保留原件和明确的不可自动定稿风险。ZIP 展开、对象数量、文本和图片尺寸必须有总预算、超时、取消与恢复边界。

同时核对 .doc、BMP 等“界面可选而处理不通”的格式矩阵；按实际解析器能力接通，不能只扩展文件选择器。原先已导入的测试资料可按用户授权显式重新整理，正式教师事实仍受版本和来源守卫。完成定义仍包括真实文件夹→完整来源图文→题库→小智实读/相似题→整卷确认，而非只有结构解析脚本通过。
