## 代码与UI分工

- 唯一开发分支：`codex/hana-answer-quality`，复用现分支，不为每个模块另开分支。
- 本会话负责 `shared/`、`main/`、Worker、typed preload和基座测试。**从本指令起不再修改renderer、页面CSS或已冻结设计**；已经完成并验证的T02页面接缝随当前模块交付，后续样式和入口交UI会话。
- 每模块交接列出输入/输出类型、IPC、状态和错误码、真实调用样例、消费者及已知未完项；UI需求只写交接，不代替另一AI修改页面。
- 每模块先提交功能与必要检查，再fetch/整合最新origin/main并正常推送`HEAD:main`及本分支。不得强推、移动其他工作树的已检出分支或覆盖其脏文件。只有docs变化不重启日常软件；修改运行代码后按现授权更新D盘经验证构建。
- 不增加第二Runtime、第二任务账本或逐工具批准。教师对最终教学内容/文件的原确认保留；认可且已授权的依赖准备直接做。仅真实新增外部费用、凭证/权限变化或不可逆用户数据操作才请求必要授权。

## 按模块完成与防空转规则

1. **必须完成固定六模块全部功能及24条AT**。修复次数不作为放弃未完功能的条件。旧“模块3轮、最终2轮、总20回合即STOPPED_UNMET”自2026-11-04失效；历史失败、证据、轮次保留，不清零、不修改为通过。
2. 按模块推进，先复用满足同一标准且未受影响的证据，再补真实缺口。模块功能齐后集中验收；失败只修对应原因、重跑受影响检查，不反复跑已通过且未受影响的检查。不得通过降低阈值、删断言或缩小24条范围制造完成。
3. 每次有实质工作后记录：当前模块/需求ID、实际变更或新证据、剩余缺口、下一具体动作。实现/修复轮次和工作回合只作累计记录。每累计20个工作回合做一次进度检查点，明确已完成与剩余功能后继续实施，**检查点不是停止点**。
4. **空转**指连续工作回合既无代码/功能进展，也无新诊断/证据，重复同一动作或同一未变条件下的测试。连续3个无进展回合必须复盘原因并改变方法，不得继续原样重试；有可执行替代方案则继续，有不依赖该阻点的模块则先推进。只有相同阻点连续至少3回合且没有可行替代、必须用户输入或外部状态改变，才标BLOCKED并停止自动重试。新失败定位和有效修复属于进展，不算空转。
5. 一条完整AT通过后标“**已实现**”，记录源码SHA、实际运行根、命令/输入、结果和证据。只完成工程子项则标“部分实现”；Mock或受控模型输出不能冒充自然教学质量验收。
6. 必要门禁：相关领域/契约测试一次；桌面代码构建与组件门禁一次；关键共享路径改变时一次仓库smoke；收尾diff检查。仅文档更新不触发桌面全量回归或日常重启，不增加通用安全审核轮次。实际typed IPC/主进程、SQLite/文件和请求回执证明基座能力，不等待另一会话美化UI。
7. 新增付费模型请求预算仍为0。使用本地受控传输验证生产调用链；自然模型A/B另需费用授权，不作为本期无限等待条件。真实外部费用/凭证/不可逆数据/协作所有权冲突才请求具体决定；已授权、可逆的实施直接推进。
8. **完成立即结束**：24条全部通过、六模块正常整合main且实际运行版本一致、无未关闭P0/P1，即DONE。只出一次最终报告，不再自动研究竞品、扩Backlog或追加“更智能”等开放标准。用户要求停止时保存现场立即停止；本轮结束不是Goal完成。

## 状态与停止条件

| 状态 | 判定 | 必须动作 |
| --- | --- | --- |
| ACTIVE | 固定范围仍有未完功能且能推进 | 继续按模块实施，保留真实失败，不按次数放弃 |
| DONE | 固定24条AT通过，无未关闭P0/P1，模块均正常整合main，实际运行版本一致 | 更新达标项“已实现”，出最终报告并结束，不继续Backlog |
| BLOCKED | 同一外部阻点连续至少3个无进展回合，替代路径耗尽，必须用户输入或外部变化 | 保存现场、确切阻点和恢复条件，停止相同重试；不宣称功能完成 |
| NEEDS_DECISION | 实施确实需要新范围/费用/凭证/不可逆数据，或无法安全分离协作者重叠修改 | 提出具体必要决定；不依赖该决定的工作继续，等待不等于同意 |
| CANCELLED | 用户明确要求停止或更换目标 | 保存现场与进度并结束，不派生新任务 |

2026-11-03的STOPPED_UNMET是旧规则下的历史状态，不能继续阻止本次用户已明确恢复的实施。工具层Goal状态与文档分开记录：仅在实际完成时complete；blocked/paused按工具自身规则，不能伪称已更新工具目标或状态。旧Goal卡若仍带旧上限，应使用下面简短目标替换，其余细则按本文读取。
