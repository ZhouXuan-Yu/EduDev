## 保留的产品范围与实现顺序

目标是本地优先、低操作量的教师知识库：一次选择资料或目录，后台可恢复处理，正文/题图/来源与答案角色完整保存，自动整理确定内容并集中呈现真实歧义；小智能找题、读题和按蓝图组卷，经教师确认导出。PDF 和题册是可替换验收样本，不允许按书名/页号/题号编写生产特例。

| 阶段 | 教师结果 | 范围 |
| --- | --- | --- |
| P1 | 导入→后台整理→题库→小智实读 | 复用持久队列、授权、索引与原 UI，正常项继续，异常可定位/重试/恢复 |
| P2 | 带图题与答案增强 | 图文/跨页/公式完整性、答案册配对、授权外部参考与核验写回；自动稿不等于教师确认 |
| P3 | 检索与组卷交付 | 硬条件、召回、去重、重排、来源、完整读题、正式学生/教师卷 |
| P4 | 大库、安装与移植 | 资源预算、故障恢复、受管组件、一致备份与异机恢复 |

这些是既有功能范围，不代表每阶段已通过，也不授权自动上传、收费调用、安装、提交或推送。新云端处理必须遵循实际授权及 [AGENTS](../../AGENTS.md) 的现行数据保护；不能把旧范围描述当作扩大权限。

### 明确验收标准（全部为待达成要求）

| ID | 结果 | 通过条件 |
| --- | --- | --- |
| KB-A01 | 一次导入、后台完成 | 正式导航选择含至少3层子目录的混合文件夹，PDF/DOCX/PNG/JPEG/常用文本按已声明支持范围处理；其他格式明确失败/转换需求。配置本批选项后不再逐文件/逐页点击。100%发现文件有持久状态与原因，正常项独立推进，封面不造题，摘要只汇报必要结果。 |
| KB-A02 | 规范题库与带图 | 原题、选项、小问、表格/公式、题图和答案角色可持续保存/编辑/定位。必要图提取率≥95%，进入可用稿的归属准确率100%，原图必要标注不丢。图题实际在题本/Pi/组卷/导出显示，不只存在于数据库或文字概述。 |
| KB-A03 | 自动整理质量 | 集中验收用≥120道去重自然题、开发/留出各60且按文件/章节分离，包含≥40图题/10跨页/10公式或表格题，类别可重叠。清晰且声明支持的预先冻结范围题目检出≥98%、完整可用自动稿覆盖≥90%；可用稿中发现的实质题面错误、错误答案或解析矛盾为0。独立原件/答案对照，模型自评不计标签；全部待核不能通过。 |
| KB-A04 | 配答与联网闭环 | 无歧义答案册配对覆盖≥95%、自动应用准确率100%，错卷/同号串题为0，不覆盖教师修改。≥20道缺答真实题及≥10个近似题/无结果反例覆盖浏览器搜题、同题核对、证据、核验、写回和冷读；有效补答覆盖≥80%、自动应用同题准确率100%，其余明确待核。已知答案/网页摘录不自动等于正确。 |
| KB-A05 | 检索可用、召回准确 | 小智从正式对话按知识点、相似题和结构条件调用原工具；完整返回题图与依据。≥200条独立标注留出查询分层测评，Recall@20≥95%、Precision@5≥85%，给出标注范围和错误归因；覆盖不全/预算耗尽真实提示，禁止把截断结果称全库查完。 |
| KB-A06 | 能真实组卷交付 | 3套不同蓝图，每套≥20题/100分，覆盖带图题；满足声明的知识点/难度/去重/来源和分值约束。正式集中确认后生成学生与教师DOCX/PDF；原生Office/WPS抽查图表、公式、分页和答案隔离。缺额明确报告，不能AI补题冒充库内原题。 |
