# 13 — Extension & Environment

## 1. Extension 定义

Extension 是影响 Pi Runtime 生命周期、事件、工具注册或上下文的代码扩展；与纯说明型 Skill 分开。不得因为 Skill 包含 scripts 就直接执行。

## 2. 执行隔离

- 内置可信扩展可按应用发布策略运行。
- 外部 Extension 默认隔离进程/受控 Worker/沙箱，具体能力由当前 Electron/Node 平台支持决定。
- 未验证第三方代码不得进入 Electron 主进程。
- 明确文件、网络、进程、秘密、IPC 和资源限制。
- 支持取消、超时、健康检查、日志、版本和撤销。

## 3. Extension Lifecycle

发现 → 来源/许可证/完整性检查 → 依赖解析 → 隔离测试 → 权限评估 → 授权 → 安装 → 注册 → 运行 → 健康监测 → 更新/禁用/撤销/回滚。

## 4. Environment Manager

负责诊断本地平台、Node/Python/runtime 版本、依赖、目录、配置、端口和服务状态。将“可自动生成的非敏感配置”与“必须由用户提供的凭据”分开。

## 5. 依赖安装

记录包名、版本范围、锁定版本、来源、许可证、哈希、安装脚本、目标环境和回滚策略。优先锁版本和可复现安装；未知安装脚本需隔离检查。完全授权模式仅在已授权目录/命令/来源范围内自动安装。

## 6. 配置与秘密

普通配置可生成草稿、校验和写入已授权目录。API Key/密码/Token 不得猜测、搜索窃取或写入 Skill/日志/JSONL；通过现有安全密封存储和安全输入界面处理。Provider 只获得必要秘密引用。

## 7. 验收

未授权 Extension 不进入主进程；依赖安装可审计可回滚；非敏感配置可自动修复；缺少凭据时清晰申请；撤销后阻止执行；平台兼容性和离线状态明确。
