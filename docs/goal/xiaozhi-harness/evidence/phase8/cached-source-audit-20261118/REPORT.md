## 给 core 的收敛顺序

先做第1项同 owner stdio 对象复用与第4项批量 Registry 读，均可沿现有 identity/revision 机制减少重复工作。第2项 client 复用/按需连接牵涉生命周期与 schema 校验时机，需固定 cached Pi5 主链的真实前后值。第5项 writer connection 复用应先取 queue/open/commit 分段，避免把 Windows 调度/磁盘等待误判为 JS 验证。
