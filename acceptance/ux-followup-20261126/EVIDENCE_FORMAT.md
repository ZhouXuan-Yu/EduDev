# 发布证据的字节约定

第一次暂存检查发现JSON/文本原件的CRLF被Git的diff检查识别为行尾空白，HANDOFF另有一个文件末尾空行。该检查失败保留于本轮工具记录；尚未提交或推送时已修复。

原测试输出不覆盖。collect-delivery.mjs只为发布副本统一LF并去掉行尾空白和末尾多余空行，保留原件与发布副本各自SHA256；没有改观察、断言或结果值。delivery-evidence/.gitattributes禁止后续自动换行转换，保证索引中的发布字节摘要在签出后可核验。图片直接按原字节复制。

完整原件、独立数据和profile留在本机；版本库仅包含审核过的报告、日志及虚构数据截图。
