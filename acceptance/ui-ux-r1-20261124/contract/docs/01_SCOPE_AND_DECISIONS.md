## 继续有效的仓库合同

- 当前 Agent Runtime、SQLite / 文件数据真源、typed IPC、教师确认和隐私边界。
- 现有 UI 最终交接的导航 / 布局方向、组卷 V3 的完整题目主区与同一题组协同。
- 2026-11-24 主线的追加消息队列、中文命令与 PiComposerPendingPanel：单会话一个面板、可切换事项、可收起恢复、保留输入、不抢焦点、提交沿原宿主、办结留痕。
- 右栏由老师主动打开，普通工具事件不抢占；复杂编辑进入原工作面。
- 原界面已批准的样式方向与实际产品验收是两回事；不得用旧设计批准证明当前页面已通过。

## 尚在讨论，不作为 R1 全量改造目标

1. 将问小智 / 我的任务 / 教学工作台重新划分为新的全局架构。
2. 将教学工作台首屏改成“继续工作 + 我的教学成果”。当前合同仍以教学任务和专业入口为职责。
3. 将所有设置强制归并为此前示意的六个固定分类，或改为新独立原生窗口。
4. 新的版本比较系统、全新 PPT 编辑器、全新 OCR / 题库流程、更多市场或能力配置后台。

执行 AI 可在既有合同内整理间距、行项、分组、标题、辅助说明和操作层级；不可把上面提案直接写成“用户已确认”。必要的新产品决策单独记录在 FOLLOW_UP，不阻塞已授权且可独立的修复。

## 本轮范围冻结方法

Phase 0 对照当前 page-contracts.ts 的 18 个已知页面及实际入口：teaching、my_tasks、student_workbench、ai、knowledge、artifacts、notebook、book、question_notebook、paper、students、search、intake、mistakes、mastery、review、analytics、settings。

全部进行位置、布局、状态与共享控件检查。涉及设置子页、详情、菜单、弹层、编辑 / 预览的缺陷要附在所属页面下，不能因它们不是一级页面而漏掉。

执行时新出现的页面先登记：若属于同一已授权流程或共享改动直接影响，作为必要回归纳入；完全新增的领域能力留给后续。不用增设页面数量目标衡量完成。

## 旧 36 项与本轮 28 项

两者编号独立。templates/LEGACY_GATE_MAP.csv 提供 A01–A36 的逐项映射起点。执行方核实哪些受本轮影响、哪些保护行为需要复验、哪些有可继承且未被改动破坏的真实证据。

不得删除旧门禁、改为 N/A、伪造历史 PASS 或靠更新指纹“修好”失败。确属本轮之外的旧业务缺口，记录旧项原状态和责任，不以本轮 UI_R1_DONE 冒充 UI-FINAL 完整 DONE。若缺口阻断本轮三条核心路径或必选项，则本轮也是 BLOCKED。

## 严重程度

- S0：数据损失、越权、确认被绕过、错误对象写入等保护性问题。
- S1：核心路径无法完成、无法返回、主要操作不可达、崩溃或持续冻结。
- S2：已冻结验收不满足，例如主次不清、选中混淆、必需文字被截掉、错误显示为空、失去键盘操作。
- S3：不影响本轮验收的新偏好 / 美化建议。进入后续，不持续打磨；不能将必选失败降级 S3。
